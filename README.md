## 时间与生活

- 新阶段按精力弹性安排：恢复日**45–90分钟**，标准日**150–180分钟**，高精力日可选**180–240分钟**，不设强制达标时长；细节见[两个月计划](INTERVIEW_2MONTH_COLLAB_2026.md)。
- 正常日先用约**10–15分钟**主动回忆和检查最新实际进度，计入当天总学习时长；复习仍根据真实弱点安排，不把复习叠加为额外强制任务。
- 旧日历中的求职、项目开发、健身和游戏预算仅供回看。新阶段建议求职每周3–5次、每次30–60分钟；**不强制每天额外3小时开发**，保障睡眠、休息和运动。
- 旧计划标注的自由日仍可休息；新阶段**每周至少一天不强制学习**，具体安排依身体状态与面试调整。
- 临时面试/外出/疲劳时整体顺延，不熬夜、不取消休息；月底不是硬截止。

## 每天怎么找到任务

直接对ChatGPT说**「开始学习」**（可加「今天90分钟／精力2/5」）。助手先看[当前进度](STUDY_PROGRESS.md)、[两个月优先级](INTERVIEW_2MONTH_COLLAB_2026.md)与复习队列，再结合原课程编号、需要的GUI源码与用户状态，为本次选择**一个主目标＋一个项目/面试连接**。原日历页仍是知识入口而非每日强制列表。

每课包含先修、讲解、例题、独立练习、答案和验收。每次开课先用10分钟闭卷回忆之前内容，再进入新课；不会时先补具体基础，不能只勾选看过。到期短复习按实际通过日期+1/+3/+7/+14天安排，并优先占用这10分钟。
