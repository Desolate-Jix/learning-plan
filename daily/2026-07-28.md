## 主任务｜1004. Max Consecutive Ones III

[打开题目](https://leetcode.com/problems/max-consecutive-ones-iii/)

- **难度：** Medium
- **主题：** 可变长度滑动窗口
- **目标复杂度：** `O(n)` 时间、`O(1)` 额外空间

### 题目目标

数组只包含 `0` 和 `1`，最多可以把 `k` 个 `0` 变成 `1`，返回最长连续区间长度。

合法窗口条件：

```text
窗口中的 0 数量 <= k
```

### 今天想到的两种实现

#### 版本 A：标准可变滑动窗口

```text
right 每轮向右扩张
遇到 0，zero++
zero > k 时，left 向右收缩直到重新合法
每轮记录 right - left + 1
```

代码结构：

```java
int left = 0;
int zero = 0;
int answer = 0;

for (int right = 0; right < nums.length; right++) {
    if (nums[right] == 0) {
        zero++;
    }

    while (zero > k) {
        if (nums[left] == 0) {
            zero--;
        }
        left++;
    }

    answer = Math.max(answer, right - left + 1);
}
```

#### 版本 B：自己想到的“不缩短最大窗口”版本

核心想法：

```text
右边界加入一个元素后，如果 zero <= k：
窗口长度增长，可以刷新最大值。

如果 zero > k：
左右边界都向右移动一位，窗口长度不变。
这一轮不可能产生更大的答案，因此不更新 answer。
```

该思路本身可以成立，但实现时必须统一边界含义，并同步维护：

```text
右边进入 0 → zero++
左边离开 0 → zero--
```

更简洁的实现形式：

```java
int left = 0;
int zero = 0;

for (int right = 0; right < nums.length; right++) {
    if (nums[right] == 0) {
        zero++;
    }

    if (zero > k) {
        if (nums[left] == 0) {
            zero--;
        }
        left++;
    }
}

return nums.length - left;
```

### 今天的调试记录

1. **内层 `while` 中的 `continue` 只继续最近的 `while`**，不会进入外层 `for`。
2. `continue outer` 可以进入带标签的外层循环，但必须确认：
   - 右边界是否已经移动；
   - 左边离开的元素是否已经从 `zero` 中扣除；
   - 控制流中没有 `return` 放在 `continue` 前面。
3. `return` 后面的语句不可达，会报：

```text
unreachable statement
```

4. 如果方法存在正常走到结尾却没有返回值的路径，会报：

```text
missing return statement
```

5. 窗口两端都包含时：

```text
窗口长度 = right - left + 1
```

如果使用半开区间 `[left, right)`：

```text
窗口长度 = right - left
```

6. 最主要的实现困难不是算法想法，而是同时混用了：
   - 包含式边界与半开区间；
   - 手动移动 `j` 与 `for` 自动移动；
   - 多层 `while`、标签 `continue` 和提前 `return`。
