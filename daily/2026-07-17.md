## 自己最终 Accepted 的代码

```java
class Solution {
    public void moveZeroes(int[] nums) {
        int counter = 0;
        int l = nums.length;

        for (int i = 0; i < l; i++) {
            if (nums[i] == 0) {
                counter++;
            } else {
                nums[i - counter] = nums[i];
            }
        }

        for (int j = l - 1, q = 0; q < counter; q++) {
            nums[j] = 0;
            j--;
        }
    }
}
```

## 算法思路

1. 从左向右扫描数组；
2. `counter` 记录已经遇到的零的数量；
3. 遇到非零元素时，把它写到 `i - counter`；
4. 扫描结束后，把末尾 `counter` 个位置补成零。

例如：

```text
[0,1,0,3,12]
```

第一遍把非零元素按原顺序压到前面：

```text
[1,3,12,3,12]
```

后面的重复旧值只是临时状态。第二遍补零后得到：

```text
[1,3,12,0,0]
```

## `i - counter` 是隐式写入指针

- `i`：当前扫描位置；
- `counter`：前面出现过多少个零；
- `i - counter`：当前非零元素应该写到的位置。

所以本题仍然属于同方向快慢双指针，只是没有单独声明 `write`，而是通过公式计算写入位置。

## 今日 Java 知识

### 数组不能真正 `add`

数组长度创建后固定，只能修改已有位置：

```java
nums[index] = value;
```

本题是在同一个数组中搬移和覆盖元素，不是在数组末尾添加新元素。

### `void` 表示不返回值

方法签名：

```java
public void moveZeroes(int[] nums)
```

LeetCode 会检查被直接修改后的 `nums`，因此不能写：

```java
return nums[];
```

## 今天出现的错误

| 问题 | 原因 | 修正 |
|---|---|---|
| `return nums[];` 编译失败 | 方法返回类型是 `void`，而且 `nums[]` 不是合法表达式 | 不返回数组，方法直接结束 |
| 询问“怎么给数组加东西” | 把固定长度数组与可扩容 List 混淆 | 数组只能覆盖已有位置 |
| 第二个循环最初没有移动 `j` | 每轮都只重复修改最后一个位置 | 每轮执行 `j--`，依次补齐末尾多个零 |

## 推荐的显式写入指针版本

```java
class Solution {
    public void moveZeroes(int[] nums) {
        int write = 0;

        for (int scan = 0; scan < nums.length; scan++) {
            if (nums[scan] != 0) {
                nums[write] = nums[scan];
                write++;
            }
        }

        while (write < nums.length) {
            nums[write] = 0;
            write++;
        }
    }
}
```

对应关系：

```text
i                  = scan
i - counter        = write
counter            = 已跳过的零数量
```
