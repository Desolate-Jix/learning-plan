## 先理解两个“指针”是什么

它们仍然只是两个整数下标：

```java
int write = 0;
int scan = 0;
```

- `scan`：从左到右检查每个元素；
- `write`：记录“下一个非零元素应该放到哪里”。

用例：

```text
nums = [0, 1, 0, 3, 12]
下标 =  0  1  2  3   4
```

开始：

```text
write = 0
scan  = 0
```

当 `scan` 找到 `1` 时，应该把它放到 `write = 0` 的位置，然后 `write++`。

随后继续扫描，找到 `3`、`12`，依次放到前面。最终非零元素顺序必须保持：

```text
[1, 3, 12, 0, 0]
```

今天重点不是记代码，而是回答：

> 为什么 `scan` 每次都移动，而 `write` 只有遇到非零元素时才移动？

## 题目要求中的两个关键词

### 1. 保持相对顺序

输入非零元素顺序：

```text
1 → 3 → 12
```

输出仍然必须是：

```text
1 → 3 → 12
```

不能变成 `12 → 3 → 1`。

### 2. 原地修改（in-place）

方法返回类型是 `void`，说明不需要返回新数组：

```java
public void moveZeroes(int[] nums)
```

你要直接修改传进来的 `nums`。

## 今天可能用到的 Java 语法

读取数组元素：

```java
nums[scan]
```

修改数组元素：

```java
nums[write] = nums[scan];
```

交换两个位置：

```java
int temp = nums[write];
nums[write] = nums[scan];
nums[scan] = temp;
```

数组长度：

```java
nums.length
```

注意方法返回 `void`，最后通常不写：

```java
return nums;
```
