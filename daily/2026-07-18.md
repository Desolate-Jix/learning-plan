## 自己最终 Accepted 的代码

```java
class Solution {
    public int maxArea(int[] height) {
        int maxSquare = 0;
        int n = height.length;
        int i = 0;
        int j = n - 1;

        while (i < j) {
            int square = (j - i) * Math.min(height[i], height[j]);

            if (square > maxSquare) {
                maxSquare = square;
            }

            if (height[i] > height[j]) {
                j--;
            } else {
                i++;
            }
        }

        return maxSquare;
    }
}
```

## 面积公式

```java
int width = j - i;
int validHeight = Math.min(height[i], height[j]);
int area = width * validHeight;
```

水位由较短的一边决定，因为水会从较短边溢出。

## 从暴力解法到双指针

### 第一版：暴力枚举

```java
for (int i = 0; i < n; i++) {
    for (int j = i + 1; j < n; j++) {
        int area = (j - i) * Math.min(height[i], height[j]);
    }
}
```

这版逻辑正确，示例得到 `49`，但提交时只通过 59 / 65，出现 `Time Limit Exceeded`。

原因是要检查大约：

```text
n × (n - 1) / 2
```

个组合，时间复杂度为 `O(n²)`。

### 第二版：左右双指针

```java
int i = 0;
int j = height.length - 1;
```

每轮只计算当前最外侧两根线，然后移动较短的一边。左右指针最多各走一遍数组，所以时间复杂度降为 `O(n)`。

## 为什么移动较短的一边

假设：

```text
左边高度 = 3
右边高度 = 8
```

当前有效高度只能是 `3`。

如果移动较高的右边：

- 宽度变小；
- 左边的 `3` 仍然限制水位；
- 新面积不可能比当前更大。

只有移动较短的左边，才有机会找到一根更高的线，从而弥补宽度减少。

最终代码中：

```java
if (height[i] > height[j]) {
    j--;
} else {
    i++;
}
```

- 右边较短：`j--`；
- 左边较短或两边相等：`i++`。

两边高度相等时移动任意一边都可以，因为当前有效高度相同，而宽度下一步必然减小。

## 今天出现的错误与调试过程

| 问题 | 原因 | 修正 |
|---|---|---|
| `variable i might not have been initialized` | `for (int i, j = 0; ...)` 只初始化了 `j` | 分别初始化，或写标准双重循环 |
| 外层条件写 `i < n && j < n` | 内层结束后 `j == n`，外层不会继续下一轮 | 外层只控制 `i`；内层重新声明 `j = i + 1` |
| 暴力版提交超时 | 双重循环为 `O(n²)` | 改为左右双指针 `O(n)` |

## 推荐可读版本

```java
class Solution {
    public int maxArea(int[] height) {
        int left = 0;
        int right = height.length - 1;
        int maxArea = 0;

        while (left < right) {
            int width = right - left;
            int currentHeight = Math.min(height[left], height[right]);
            int area = width * currentHeight;
            maxArea = Math.max(maxArea, area);

            if (height[left] < height[right]) {
                left++;
            } else {
                right--;
            }
        }

        return maxArea;
    }
}
```

## 复杂度

- **暴力版时间复杂度：** `O(n²)`
- **双指针时间复杂度：** `O(n)`
- **额外空间：** `O(1)`
