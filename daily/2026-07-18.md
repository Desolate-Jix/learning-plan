## 先理解题目中的面积

数组中的每个数字表示一根竖线的高度：

```text
height = [1, 8, 6, 2, 5, 4, 8, 3, 7]
下标      0  1  2  3  4  5  6  7  8
```

选左右两根线后：

```text
宽度 = right - left
有效高度 = 两根线中较短的一根
面积 = 宽度 × 有效高度
```

Java 中：

```java
int width = right - left;
int containerHeight = Math.min(height[left], height[right]);
int area = width * containerHeight;
```

注意：水会从较短的一边溢出，所以高度必须取 `Math.min()`，不能取较高的一边。

## 今天要理解的双指针模型

```java
int left = 0;
int right = height.length - 1;
```

开始时选择最宽的容器。每轮：

1. 计算当前面积；
2. 更新目前最大面积；
3. 比较左右两根线的高度；
4. 移动较短的一边；
5. `left >= right` 时结束。

核心问题：

> 为什么移动较短的一边，而不是移动较高的一边？

直觉：宽度下一步一定会变小。如果保留较短边、只移动较高边，有效高度仍然不会超过那根较短边，因此面积不可能因为这次移动而变大。想找到更大的面积，只能尝试换掉当前较短的边。

    public int maxArea(int[] height) {
        int left = 0;
        int right = height.length - 1;
        int maxArea = 0;

        while (left < right) {
            // 1. 计算宽度

        }
