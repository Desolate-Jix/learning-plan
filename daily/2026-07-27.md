# LeetCode A｜1456. Maximum Number of Vowels in a Substring of Given Length

[打开题目](https://leetcode.com/problems/maximum-number-of-vowels-in-a-substring-of-given-length/)

## 完成结果

- **中文：** 定长子串中元音的最大数目
- **难度：** Medium
- **结果：** Accepted，107 / 107
- **提交记录：** 21 ms、46.53 MB；单次排名只作参考
- **掌握等级：** B+
- **时间复杂度：** `O(n)`
- **额外空间：** `O(1)`

## 自己最终 Accepted 的代码

```java
class Solution {
    public int maxVowels(String s, int k) {
        int current = 0;
        int max = 0;
        int n = s.length();
        String vowels = "aeiouAEIOU";

        for (int i = 0; i < k; i++) {
            if (vowels.indexOf(s.charAt(i)) != -1) {
                current++;
            }

            if (current > max) {
                max = current;
            }
        }

        // i 表示新窗口的起点
        for (int i = 1; i + k <= n; i++) {
            if (vowels.indexOf(s.charAt(i - 1)) != -1) {
                current--;
            }

            if (vowels.indexOf(s.charAt(i + k - 1)) != -1) {
                current++;
            }

            if (current > max) {
                max = current;
            }
        }

        return max;
    }
}
```

## 核心算法

```text
新窗口元音数
=
旧窗口元音数
-
离开字符是否为元音
+
进入字符是否为元音
```

第二个循环里，`i` 表示新窗口起点。长度为 `k` 的窗口范围是：

```text
i, i + 1, ..., i + k - 1
```

因此：

```text
离开字符：i - 1
进入字符：i + k - 1
```

循环条件：

```java
i + k <= n
```

等价于：

```java
i + k - 1 < n
```

必须允许最后一个合法窗口满足 `i + k == n`。

## 调试记录

### 1. `contains()` 不能直接接收 `char`

错误方向：

```java
vowels.contains(s.charAt(i))
```

`charAt()` 返回 `char`，而 `String.contains()` 接收 `CharSequence`。改用：

```java
vowels.indexOf(s.charAt(i)) != -1
```

### 2. 漏掉最后一个合法窗口

暴力版本最初使用：

```java
i + k < n
```

会漏掉 `i + k == n` 的最后一个窗口。正确条件：

```java
i + k <= n
```

### 3. 进入字符下标写错

错误：

```java
i + k + 1
```

正确：

```java
i + k - 1
```

[打开题目](https://leetcode.com/problems/find-the-difference-of-two-arrays/)

## 完成结果

- **中文：** 找出两数组的不同
- **难度：** Easy
- **结果：** Accepted，202 / 202
- **实际用时：** 约 24 分 51 秒
- **提交记录：** 13 ms、47.67 MB；单次排名只作参考
- **掌握等级：** B+
- **主题：** `HashSet`、自动去重、`contains()`、增强 `for`、嵌套 `List`
- **平均时间复杂度：** `O(n + m)`
- **额外空间：** `O(n + m)`

## 自己最终 Accepted 的代码

```java
class Solution {
    public List<List<Integer>> findDifference(int[] nums1, int[] nums2) {
        Set<Integer> n1 = new HashSet<>();
        Set<Integer> n2 = new HashSet<>();

        for (int num : nums1) {
            n1.add(num);
        }

        for (int num : nums2) {
            n2.add(num);
        }

        List<List<Integer>> answer = new ArrayList<>();
        Set<Integer> a = new HashSet<>();
        Set<Integer> b = new HashSet<>();

        for (int j : nums1) {
            if (!n2.contains(j)) {
                a.add(j);
            }
        }

        for (int k : nums2) {
            if (!n1.contains(k)) {
                b.add(k);
            }
        }

        List<Integer> list1 = new ArrayList<>(a);
        List<Integer> list2 = new ArrayList<>(b);

        answer.add(list1);
        answer.add(list2);

        return answer;
    }
}
```

## 今天掌握的 HashSet 基础

创建：

```java
Set<Integer> set = new HashSet<>();
```

`<Integer>` 表示集合只保存 `Integer`。

加入：

```java
set.add(number);
```

判断是否存在：

```java
set.contains(number)
```

取反：

```java
!set.contains(number)
```

增强 `for`：

```java
for (int number : set) {
    // 每轮取出一个元素
}
```

`HashSet` 没有下标，不能使用 `set.get(0)`。

## 数组、List、Set 的区别

| 类型 | 长度 | `add()` | `contains()` | 下标 | 重复值 |
|---|---|---|---|---|---|
| `int[]` | 固定 | 不支持 | 不支持 | `nums[i]` | 允许 |
| `ArrayList<Integer>` | 可变 | 支持 | 支持 | `list.get(i)` | 允许 |
| `HashSet<Integer>` | 可变 | 支持 | 支持 | 不支持 | 自动去重 |

## HashSet 转 List

```java
List<Integer> list = new ArrayList<>(set);
```

表示把 Set 中的所有元素复制进新的 `ArrayList`。

## 嵌套 List

题目返回：

```java
List<List<Integer>>
```

最外层 `answer` 一开始为空，因此应使用：

```java
answer.add(list1);
answer.add(list2);
```

不能使用数组语法：

```java
answer[0] = list1; // 错误
```

## 调试记录

### 1. 文件结尾缺少右大括号

报错：

```text
reached end of file while parsing
```

原因是只关闭了方法，没有关闭 `class Solution`。

### 2. 把 List 当成数组赋值

错误：

```java
answer[0] = list1;
answer[1] = list2;
```

正确：

```java
answer.add(list1);
answer.add(list2);
```

## 可读性优化

当前版本用了四个 Set。因为 `n1` 和 `n2` 已经去重，复刷时可以直接遍历它们，把结果加入两个 List，省去中间 Set `a`、`b`。
