# LeetCode A｜1456. Maximum Number of Vowels in a Substring of Given Length

[打开题目](https://leetcode.com/problems/maximum-number-of-vowels-in-a-substring-of-given-length/)

## 完成结果

- **中文：** 定长子串中元音的最大数目
- **难度：** Medium
- **结果：** Accepted，107 / 107
- **提交记录：** 21 ms、46.53 MB；单次排名只作参考
- **掌握等级：** B+
- **时间复杂度：** `O(n)`
- **额外空间：** `O(1)`

## 自己最终 Accepted 的代码

```java
class Solution {
    public int maxVowels(String s, int k) {
        int current = 0;
        int max = 0;
        int n = s.length();
        String vowels = "aeiouAEIOU";

        // 第一个长度为 k 的窗口
        for (int i = 0; i < k; i++) {
            if (vowels.indexOf(s.charAt(i)) != -1) {
                current++;
            }

            if (current > max) {
                max = current;
            }
        }

        // i 表示新窗口的起点
        for (int i = 1; i + k <= n; i++) {
            if (vowels.indexOf(s.charAt(i - 1)) != -1) {
                current--;
            }

            if (vowels.indexOf(s.charAt(i + k - 1)) != -1) {
                current++;
            }

            if (current > max) {
                max = current;
            }
        }

        return max;
    }
}
```

> 上面只统一了缩进，保留实际提交通过的算法结构。

## 核心算法

```text
新窗口元音数
=
旧窗口元音数
-
离开字符是否为元音
+
进入字符是否为元音
```

第二个循环中，`i` 表示新窗口的起点。长度为 `k` 的窗口范围是：

```text
i, i + 1, ..., i + k - 1
```

因此：

```text
离开字符：i - 1
进入字符：i + k - 1
```

循环条件：

```java
i + k <= n
```

等价于：

```java
i + k - 1 < n
```

必须允许最后一个合法窗口满足 `i + k == n`。

## 调试记录

1. `String.contains()` 不能直接接收 `char`，改用：

```java
vowels.indexOf(s.charAt(i)) != -1
```

2. 暴力版本最初使用：

```java
i + k < n
```

会漏掉最后一个合法窗口，应该使用：

```java
i + k <= n
```

3. 滑动窗口版本最初把进入下标写成：

```java
i + k + 1
```

正确下标是：

```java
i + k - 1
```

## 完成结果

- **中文：** 找出两数组的不同
- **难度：** Easy

- **实际用时：** 约 24 分 51 秒

- **掌握等级：** B+
- **主题：** `HashSet`、自动去重、`contains()`、增强 `for`、嵌套 `List`
- **平均时间复杂度：** `O(n + m)`
- **额外空间：** `O(n + m)`

## 自己最终 Accepted 的代码

```java
class Solution {
    public List<List<Integer>> findDifference(int[] nums1, int[] nums2) {
        Set<Integer> n1 = new HashSet<>();
        Set<Integer> n2 = new HashSet<>();

        for (int num : nums1) {
            n1.add(num);
        }

        for (int num : nums2) {
            n2.add(num);
        }

        List<List<Integer>> answer = new ArrayList<>();
        Set<Integer> a = new HashSet<>();
        Set<Integer> b = new HashSet<>();

        for (int j : nums1) {
            if (!n2.contains(j)) {
                a.add(j);
            }
        }

        for (int k : nums2) {
            if (!n1.contains(k)) {
                b.add(k);
            }
        }

        List<Integer> list1 = new ArrayList<>(a);
        List<Integer> list2 = new ArrayList<>(b);

        answer.add(list1);
        answer.add(list2);

        return answer;
    }
}
```

> 上面只统一了缩进和空格，保留实际提交通过的算法结构。

## HashSet 基础

创建只保存整数的 Set：

```java
Set<Integer> set = new HashSet<>();
```

`<Integer>` 表示集合中只允许存放整数包装类型 `Integer`。

加入元素：

```java
set.add(number);
```

重复元素不会重复保存。

检查是否存在：

```java
set.contains(number)
```

取反：

```java
!set.contains(number)
```

增强 `for`：

```java
for (int number : set) {
    // 每次把 set 中的一个元素放入 number
}
```

`HashSet` 没有下标，不能使用 `set.get(0)`。

## 数组、List、Set 的区别

| 类型 | 长度 | `add()` | `contains()` | 下标 | 重复值 |
|---|---|---|---|---|---|
| `int[]` | 固定 | 不支持 | 不支持 | `nums[i]` | 允许 |
| `ArrayList<Integer>` | 可变 | 支持 | 支持 | `list.get(i)` | 允许 |
| `HashSet<Integer>` | 可变 | 支持 | 支持 | 不支持 | 自动去重 |

原生数组要检查是否包含某个值，通常自己遍历；需要频繁判断存在性时，可以先放入 `HashSet`。

## HashSet 转 List

```java
List<Integer> list = new ArrayList<>(set);
```

意思是把 Set 中的所有元素复制进新的 `ArrayList`。

## 嵌套 List

题目返回类型：

```java
List<List<Integer>>
```

可以理解成：

```text
最外层 List
├── 第 0 个 List：只在 nums1 中出现
└── 第 1 个 List：只在 nums2 中出现
```

最外层 `answer` 一开始为空，因此应使用：

```java
answer.add(list1);
answer.add(list2);
```

不能使用数组语法：

```java
answer[0] = list1; // 错误
```

也不能一开始使用 `set(0, list1)`，因为位置 `0` 尚不存在。

## 核心算法

```text
1. nums1 → n1，自动去重
2. nums2 → n2，自动去重
3. nums1 中不在 n2 的数字 → a
4. nums2 中不在 n1 的数字 → b
5. a、b 转成 List
6. 加入 answer 并返回
```

## 复杂度

设两个数组长度分别为 `n` 和 `m`：

- 建立两个 Set：平均 `O(n + m)`；
- 遍历两个数组并进行 `contains()`：平均 `O(n + m)`；
- 转换并构建答案：最多 `O(n + m)`；
- **总平均时间复杂度：** `O(n + m)`；
- **额外空间：** `O(n + m)`。

## 可读性优化

当前版本逻辑正确，但可以减少两个中间 Set `a`、`b`。因为 `n1` 和 `n2` 已经去重，可以直接遍历它们并加入 List：

```java
List<Integer> onlyInFirst = new ArrayList<>();
List<Integer> onlyInSecond = new ArrayList<>();

for (int number : n1) {
    if (!n2.contains(number)) {
        onlyInFirst.add(number);
    }
}

for (int number : n2) {
    if (!n1.contains(number)) {
        onlyInSecond.add(number);
    }
}
```

这只是减少中间容器，当前 Accepted 方案不需要立即重写。
