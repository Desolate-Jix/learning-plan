# LeetCode A｜1456. Maximum Number of Vowels in a Substring of Given Length

[打开题目](https://leetcode.com/problems/maximum-number-of-vowels-in-a-substring-of-given-length/)

## 完成结果

- **中文：** 定长子串中元音的最大数目
- **难度：** Medium
- **结果：** Accepted，107 / 107
- **提交记录：** 21 ms、46.53 MB；单次排名只作参考
- **掌握等级：** B+
- **时间复杂度：** `O(n)`
- **额外空间：** `O(1)`

## 自己最终 Accepted 的代码

```java
class Solution {
    public int maxVowels(String s, int k) {
        int current = 0;
        int max = 0;
        int n = s.length();
        String vowels = "aeiouAEIOU";

        // 第一个长度为 k 的窗口
        for (int i = 0; i < k; i++) {
            if (vowels.indexOf(s.charAt(i)) != -1) {
                current++;
            }

            if (current > max) {
                max = current;
            }
        }

        // i 表示新窗口的起点
        for (int i = 1; i + k <= n; i++) {
            if (vowels.indexOf(s.charAt(i - 1)) != -1) {
                current--;
            }

            if (vowels.indexOf(s.charAt(i + k - 1)) != -1) {
                current++;
            }

            if (current > max) {
                max = current;
            }
        }

        return max;
    }
}
```

> 上面只统一了缩进，保留实际提交通过的算法结构。

## 核心算法

先统计第一个长度为 `k` 的窗口中的元音数量，然后每次把窗口向右移动一格：

```text
新窗口元音数
=
旧窗口元音数
-
离开字符是否为元音
+
进入字符是否为元音
```

不需要为每一个窗口重新遍历全部 `k` 个字符。

## 当前写法的下标含义

第二个循环中：

```java
for (int i = 1; i + k <= n; i++)
```

`i` 表示**新窗口的起点**。

长度为 `k`、起点为 `i` 的窗口范围：

```text
i, i + 1, ..., i + k - 1
```

所以：

```text
离开旧窗口：i - 1
进入新窗口：i + k - 1
```

对应代码：

```java
s.charAt(i - 1)
s.charAt(i + k - 1)
```

## 为什么循环条件有等号

最后一个合法窗口可以正好结束在字符串最后一位。

最后一个合法下标必须满足：

```text
i + k - 1 < n
```

两边加 `1`：

```text
i + k <= n
```

因此应写：

```java
i + k <= n
```

而不是：

```java
i + k < n
```

例如：

```text
n = 9
k = 3
最后一个窗口起点 i = 6
窗口下标 = 6, 7, 8
此时 i + k = 9，正好等于 n，仍然合法
```

## 今日调试过程

### 1. `contains()` 不能直接接收 `char`

原写法：

```java
vowels.contains(s.charAt(j))
```

`charAt()` 返回 `char`，而 `String.contains()` 接收字符串类型。改为：

```java
vowels.indexOf(s.charAt(j)) != -1
```

### 2. 暴力版本漏掉最后一个窗口

原条件：

```java
i + k < n
```

当 `i + k == n` 时，窗口仍然合法，所以应为：

```java
i + k <= n
```

### 3. 进入字符下标写多了 `+1`

错误：

```java
s.charAt(i + k + 1)
```

正确：

```java
s.charAt(i + k - 1)
```

因为窗口最后一个位置是“起点 + 长度 - 1”。

## 从暴力到滑动窗口

暴力版本：

```text
每一个窗口都重新数 k 个字符
时间复杂度 O(n × k)
```

滑动窗口版本：

```text
第一个窗口统计一次
之后每轮只处理一个离开字符和一个进入字符
时间复杂度 O(n)
```

## 可以改进的地方

题目约束中字符串只有小写英文字母，因此：

```java
String vowels = "aeiou";
```

已经足够，不需要大写元音。

第一个窗口全部统计完后再赋值更清楚：

```java
int max = current;
```

还可以在达到理论最大值时提前结束：

```java
if (max == k) {
    return k;
}
```

这些都只是可读性或小幅常数优化，当前算法已经是 `O(n)`。

# LeetCode B｜2215. Find the Difference of Two Arrays

[打开题目](https://leetcode.com/problems/find-the-difference-of-two-arrays/)

- **中文：** 找出两数组的不同
- **难度：** Easy
- **状态：** 待完成
- **主题：** HashSet 入门、去重、快速判断是否存在

## 题目目标

返回两个列表：

1. 在 `nums1` 中出现、但不在 `nums2` 中出现的不同数字；
2. 在 `nums2` 中出现、但不在 `nums1` 中出现的不同数字。

例如：

```text
nums1 = [1, 2, 3]
nums2 = [2, 4, 6]

结果：[[1, 3], [4, 6]]
```

## HashSet 基础

```java
import java.util.*;

Set<Integer> set1 = new HashSet<>();
Set<Integer> set2 = new HashSet<>();
```

核心操作：

```java
set1.add(number);       // 加入并自动去重
set1.contains(number);  // 判断是否存在
```

遍历：

```java
for (int number : set1) {
    // 使用 number
}
```

解题步骤：

```text
1. nums1 放进 set1
2. nums2 放进 set2
3. 遍历 set1，找 set2 不包含的值
4. 遍历 set2，找 set1 不包含的值
5. 把两个 List 放进最终答案
```

返回类型：

```java
List<List<Integer>>
```

创建结果：

```java
List<Integer> onlyInFirst = new ArrayList<>();
List<Integer> onlyInSecond = new ArrayList<>();
List<List<Integer>> answer = new ArrayList<>();
```

完成后：

```java
answer.add(onlyInFirst);
answer.add(onlyInSecond);
return answer;
```

目标复杂度：平均 `O(n + m)` 时间、`O(n + m)` 额外空间。

## 关系模型

```text
Student(student_id, name, email)
```

- 一行：一个实体记录；
- 一列：一个属性；
- 一张表：同一种实体的集合。

## 主键与外键

```text
主键 Primary Key：唯一标识本表中的一行
外键 Foreign Key：引用另一张表的主键，建立表之间的关系
```

示例：

```text
Student(
    student_id PK,
    name,
    email
)

Course(
    course_id PK,
    title
)

Enrollment(
    student_id PK, FK,
    course_id  PK, FK,
    grade
)
```

关系：

```text
Student 1 —— N Enrollment N —— 1 Course
```

## 范式

```text
1NF：每个字段只保存一个不可再分的值
2NF：非主键字段依赖整个复合主键，不只依赖其中一部分
3NF：非主键字段不依赖另一个非主键字段
```
