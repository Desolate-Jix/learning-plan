# LeetCode A｜1456. Maximum Number of Vowels in a Substring of Given Length

[打开题目](https://leetcode.com/problems/maximum-number-of-vowels-in-a-substring-of-given-length/)

- **中文：** 定长子串中元音的最大数目
- **难度：** Medium
- **主题：** 固定长度滑动窗口
- **预计时间：** 65 分钟

## 题目目标

给一个字符串 `s` 和长度 `k`，在所有长度恰好为 `k` 的连续子串中，找到元音数量最多的那个窗口，返回最大元音数。

例如：

```text
s = "abciiidef"
k = 3
```

长度为 3 的窗口依次包含：

```text
"abc"  → 1 个元音
"bci"  → 1 个元音
"cii"  → 2 个元音
"iii"  → 3 个元音
"iid"  → 2 个元音
"ide"  → 2 个元音
"def"  → 1 个元音
```

答案是 `3`。

## 和昨天题目的联系

昨天维护的是窗口和：

```text
新窗口和 = 旧窗口和 - 离开元素 + 进入元素
```

今天维护的是窗口中的元音数量：

```text
新元音数
=
旧元音数
-
离开字符是否为元音
+
进入字符是否为元音
```

不需要为每个窗口重新数一遍全部 `k` 个字符。

## 今天会用到的 Java

判断字符是不是元音：

```java
private boolean isVowel(char c) {
    return "aeiou".indexOf(c) != -1;
}
```

读取字符串字符：

```java
s.charAt(i)
```

字符串长度：

```java
s.length()
```

## 半开放代码骨架

```java
class Solution {
    public int maxVowels(String s, int k) {
        int currentVowels = 0;

        // 1. 统计第一个长度为 k 的窗口
        for (int i = 0; i < k; i++) {
            // 如果 s.charAt(i) 是元音，currentVowels++
        }

        int maxVowels = currentVowels;

        // 2. 从下标 k 开始，让窗口每次右移一格
        for (int i = k; i < s.length(); i++) {
            // 离开的字符下标：i - k
            // 进入的字符下标：i
            // 更新 currentVowels
            // 更新 maxVowels
        }

        return maxVowels;
    }

    private boolean isVowel(char c) {
        return "aeiou".indexOf(c) != -1;
    }
}
```

## 最重要的两个下标

当新字符下标是 `i` 时：

```text
进入窗口：s.charAt(i)
离开窗口：s.charAt(i - k)
```

例如 `k = 3`、`i = 3`：

```text
旧窗口下标：0, 1, 2
新窗口下标：1, 2, 3
离开：0 = i - k
进入：3 = i
```

# LeetCode B｜2215. Find the Difference of Two Arrays

[打开题目](https://leetcode.com/problems/find-the-difference-of-two-arrays/)

- **中文：** 找出两数组的不同
- **难度：** Easy
- **主题：** HashSet 入门、去重、快速判断是否存在
- **预计时间：** 50 分钟

## 题目目标

返回两个列表：

1. 在 `nums1` 中出现、但不在 `nums2` 中出现的不同数字；
2. 在 `nums2` 中出现、但不在 `nums1` 中出现的不同数字。

例如：

```text
nums1 = [1, 2, 3]
nums2 = [2, 4, 6]
```

结果可以是：

```text
[[1, 3], [4, 6]]
```

题目只需要不同数字，因此重复数字不能重复加入答案。

## 今天的新数据结构：HashSet

`HashSet` 的核心特点：

```text
只保存唯一值
可以快速判断某个值是否存在
不保证输出顺序
```

Java 写法：

```java
Set<Integer> set1 = new HashSet<>();
Set<Integer> set2 = new HashSet<>();
```

加入元素：

```java
set1.add(number);
```

判断是否存在：

```java
set2.contains(number)
```

遍历：

```java
for (int number : set1) {
    // 使用 number
}
```

可能需要的导入：

```java
import java.util.*;
```

## 解题步骤

```text
1. 把 nums1 放进 set1，自动去重
2. 把 nums2 放进 set2，自动去重
3. 遍历 set1：set2 不包含的加入 onlyInFirst
4. 遍历 set2：set1 不包含的加入 onlyInSecond
5. 把两个 List 放进最终结果
```

## 返回类型结构

题目返回：

```java
List<List<Integer>>
```

可以理解成：

```text
最外层 List
├── 第 0 个 List：只在 nums1 中
└── 第 1 个 List：只在 nums2 中
```

创建：

```java
List<Integer> onlyInFirst = new ArrayList<>();
List<Integer> onlyInSecond = new ArrayList<>();
List<List<Integer>> answer = new ArrayList<>();
```

最后：

```java
answer.add(onlyInFirst);
answer.add(onlyInSecond);
return answer;
```

## 20 分钟：理解概念

### 关系模型

关系数据库中的一张表可以看作一个关系：

```text
Student(student_id, name, email)
```

- 一行：一个实体记录；
- 一列：一个属性；
- 表：同一种实体的集合。

### 主键 Primary Key

用于唯一标识一行：

```text
Student.student_id
```

基本要求：唯一、不能为 `NULL`、尽量稳定。

### 外键 Foreign Key

引用另一张表的主键，用来建立关系：

```text
Enrollment.student_id → Student.student_id
Enrollment.course_id  → Course.course_id
```

### ER 关系

使用这三个实体：

```text
Student
Course
Enrollment
```

关系：

```text
Student 1 —— N Enrollment N —— 1 Course
```

学生与课程本来是多对多，通过 `Enrollment` 中间表拆开。

## 15 分钟：画表与规范化

画出：

```text
Student(
    student_id PK,
    name,
    email
)

Course(
    course_id PK,
    title
)

Enrollment(
    student_id PK, FK,
    course_id  PK, FK,

```

然后思考为什么下面这张大表有重复：

```text
EnrollmentRaw(
    student_id,
    student_name,
    course_id,
    course_title,
    grade
)
```

把它拆成上面的三张表。

### 范式先记住这个层级

```text
1NF：每个字段只放一个不可再分的值
2NF：非主键字段依赖整个主键，不只依赖复合主键的一部分
3NF：非主键字段不依赖另一个非主键字段
```
