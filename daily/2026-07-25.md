## 1. 自己最终 Accepted 的代码

```java
class Solution {
    public double findMaxAverage(int[] nums, int k) {
        int maxsum = 0;
        int l = nums.length;
        int t = 0;

        for (int i = 0; i < k; i++) {
            t = t + nums[i];
        }

        maxsum = t;

        for (int i = 0; i < l - k; i++) {
            if (t - nums[i] + nums[i + k] > maxsum) {
                maxsum = t - nums[i] + nums[i + k];
            }

            t = t - nums[i] + nums[i + k];
        }

        return (double) maxsum / k;
    }
}
```

> 上面只统一了缩进和空格，保留实际提交通过的算法结构。

## 2. 题目真正要求什么

在数组中寻找一个：

- **连续的**子数组；
- 长度必须恰好等于 `k`；
- 平均值最大。

例如：

```text
nums = [1, 12, -5, -6, 50, 3]
k = 4
```

合法窗口只有：

```text
[1, 12, -5, -6]   和 = 2
[12, -5, -6, 50]  和 = 51
[-5, -6, 50, 3]   和 = 42
```

因为所有窗口长度都是同一个 `k`，窗口和越大，平均值也越大。因此循环中只比较窗口和，最后再除以 `k`：

```java
return (double) maxsum / k;
```

## 3. 固定长度滑动窗口

第一个窗口需要完整计算一次：

```java
for (int i = 0; i < k; i++) {
    t += nums[i];
}
```

之后窗口每次向右移动一格：

```text
新窗口和
=
旧窗口和
-
离开窗口的元素
+
进入窗口的元素
```

代码：

```java
t = t - nums[i] + nums[i + k];
```

其中：

- `nums[i]` 是左边离开窗口的元素；
- `nums[i + k]` 是右边新进入窗口的元素；
- `t` 必须在每轮更新为当前窗口和，下一轮才能继续从当前状态滑动。

### 示例变化

```text
第一个窗口：[1, 12, -5, -6]
t = 2
```

第一次滑动：

```text
2 - 1 + 50 = 51
```

第二次滑动：

```text
51 - 12 + 3 = 42
```

## 4. 今天自己发现的关键错误：忘记更新 `t`

最初代码只写了：

```java
if (t - nums[i] + nums[i + k] > maxsum) {
    maxsum = t - nums[i] + nums[i + k];
}
```

但没有把新的窗口和保存回 `t`。

这样 `t` 会一直停留在第一个窗口，后面的窗口不能基于上一个窗口继续滑动。

修正：

```java
t = t - nums[i] + nums[i + k];
```

自己最终提交的顺序是：

```java
if (t - nums[i] + nums[i + k] > maxsum) {
    maxsum = t - nums[i] + nums[i + k];
}

t = t - nums[i] + nums[i + k];
```

这个顺序是正确的，因为比较和赋值使用的是同一个新窗口表达式。

可读性更好的常见写法是先保存新状态，再比较：

```java
t = t - nums[i] + nums[i + k];
maxsum = Math.max(maxsum, t);
```

两种写法算法等价。

## 5. 整数除法与 `double`

最初写法：

```java
float answer = maxsum / k;
```

虽然左边是 `float`，但右边 `maxsum` 和 `k` 都是 `int`。Java 会先执行整数除法：

```text
51 / 4 = 12
```

再把 `12` 转成小数：

```text
12.0
```

正确写法需要在除法之前把其中一个操作数转成 `double`：

```java
return (double) maxsum / k;
```

这样：

```text
51 / 4 = 12.75
```

## 6. 为什么 `maxsum` 用第一个真实窗口初始化

不能简单写：

```java
int maxsum = 0;
```

并一直用它比较，因为数组可能全部是负数。例如：

```text
[-5, -3, -8]
```

所有合法窗口和都可能小于 `0`。

因此先算出第一个窗口，再写：

```java
maxsum = t;
```

这样最大值的初始状态来自一个真实合法窗口。

## 7. 为什么复杂度是 `O(n)`

### 暴力法

对每个窗口重新把 `k` 个元素相加：

```text
窗口数量约 n
×
每个窗口计算 k 次
=
O(n × k)
```

当 `k` 接近 `n` 时，可退化到约 `O(n²)`。

### 滑动窗口

- 第一个窗口求和：`O(k)`；
- 剩余窗口每次只做减法、加法和比较：`O(n - k)`。

总计：

```text
O(k) + O(n - k) = O(n)
```

额外只使用几个整数变量：

```text
空间复杂度 = O(1)
```

### 可以改进

变量名可以更清楚：

```java
int windowSum = 0;
int maxWindowSum;
int n = nums.length;
```

推荐的简洁版本：

```java
class Solution {
    public double findMaxAverage(int[] nums, int k) {
        int windowSum = 0;

        for (int i = 0; i < k; i++) {
            windowSum += nums[i];
        }

        int maxWindowSum = windowSum;

        for (int i = k; i < nums.length; i++) {
            windowSum += nums[i] - nums[i - k];
            maxWindowSum = Math.max(maxWindowSum, windowSum);
        }

        return (double) maxWindowSum / k;
    }
}
```

自己的版本与该版本复杂度相同，只是下标表达方式不同。
