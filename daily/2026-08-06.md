# 任务 A｜2352. Equal Row and Column Pairs

[打开题目](https://leetcode.com/problems/equal-row-and-column-pairs/)

## 完成结果

- **难度：** Medium
- **结果：** Accepted，80 / 80
- **提交记录：** 20 ms、54.28 MB；单次排名仅作参考
- **主题：** 二维数组、HashMap、List 作为复合 key、行列索引
- **时间复杂度：** `O(n²)`
- **额外空间：** `O(n²)`
- **掌握等级：** B

### 为什么记为 B

这次能够自己从直接比较方案继续推导出 HashMap 优化方向：

1. 先想到构造列矩阵，再逐行逐列比较；
2. 进一步理解不需要保存列 Map，只需要把每种行序列及出现次数保存到 Map；
3. 每构造一列，就直接查询相同的行出现了几次；
4. 理解重复行必须分别计数，例如同一列可同时匹配两条相同的行。

但实现过程中使用了较多提示，包括：

- `List` 与 `ArrayList`、接口与具体类的区别；
- 把 `int[]` 手动转换为 `List<Integer>`；
- `containsKey()`、`get()` 和 `getOrDefault()`；
- Java 类名大小写：`Hashmap` 应为 `HashMap`；
- 构造列时需要访问 `grid[row][col]`，最终写成 `grid[j][i]`。

核心算法方向是自己理解并推进的，但代码并非完全独立完成，因此暂记 B。

## 最终 Accepted 代码

```java
class Solution {
    public int equalPairs(int[][] grid) {
        int n = grid.length;
        int counter = 0;
        Map<List<Integer>, Integer> rowmap = new HashMap<>();

        for (int[] i : grid) {
            List<Integer> list = new ArrayList<>();
            for (int j : i) {
                list.add(j);
            }
            rowmap.put(list, rowmap.getOrDefault(list, 0) + 1);
        }

        for (int i = 0; i < n; i++) {
            List<Integer> list1 = new ArrayList<>();
            for (int j = 0; j < n; j++) {
                list1.add(grid[j][i]);
            }

            if (rowmap.containsKey(list1)) {
                counter = counter + rowmap.get(list1);
            }
        }

        return counter;
    }
}
```

## 核心数据流

```text
所有行：
转成 List<Integer>
→ Map<List<Integer>, Integer> 统计出现次数

每一列：
临时构造 List<Integer>
→ 直接查询行 Map
→ 答案增加相同行的出现次数
```

不需要构造第二个列 Map，也不需要永久保存所有列。

## 关键知识点

### 1. `grid[row][col]`

二维数组的第一个下标是行，第二个下标是列。

构造第 `i` 列时，列下标 `i` 固定，行下标 `j` 变化：

```java
list1.add(grid[j][i]);
```

### 2. 为什么使用 `List<Integer>` 作为 key

不同 `List` 只要元素内容和顺序相同，`equals()` 和 `hashCode()` 就按内容判断，因此可以作为 HashMap 的复合 key。

不能直接依赖两个不同 `int[]` 对象的 `equals()` 比较内容。

### 3. 为什么 value 是出现次数

例如两行都是：

```text
[2, 4, 2, 2]
```

Map 中保存：

```text
[2, 4, 2, 2] → 2
```

当某一列也是该序列时，答案应增加 2，因为它分别和两行形成两对。

### 4. 编译错误

错误：

```java
new Hashmap<>()
```

正确：

```java
new HashMap<>()
```

Java 类名区分大小写。

## 可读性改进

后续闭卷重写时可以使用更明确的变量名：

```java
for (int[] row : grid)
for (int value : row)

```

查询列时也可以简化为：

