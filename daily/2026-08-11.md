# 任务 A｜2390. Removing Stars From a String

[打开题目](https://leetcode.com/problems/removing-stars-from-a-string/)

## 完成结果

- **难度：** Medium
- **结果：** Accepted，65 / 65
- **提交记录：** 40 ms、48.79 MB；单次排名仅作参考
- **主题：** Stack、Deque、ArrayDeque、StringBuilder
- **时间复杂度：** `O(n)`
- **额外空间：** `O(n)`
- **掌握等级：** B

### 为什么记为 B

这是第一次正式使用 Stack 数据结构。核心算法已经理解并能自己写出：

1. 从左向右扫描字符串；
2. 普通字符执行 `push`；
3. 遇到 `*` 时执行 `pop`，删除最近尚未删除的字符；
4. 最终把栈内字符恢复成字符串。

实现过程中使用了较多 Java API / 语法提示，因此暂记 B：

- `Deque<Character> stack = new ArrayDeque<>();`；
- `push()` / `pop()` / `peek()` / `isEmpty()` 的含义；
- `'*'` 是字符，需要单引号；
- `else` 代码块需要 `{}`；
- 方法返回类型是 `String`，不能直接 `return stack`；
- 因为使用 `push()` 后栈顶顺序与原字符串相反，所以通过 `StringBuilder` 逐个 `pop()` 后再 `reverse().toString()`。

## 最终 Accepted 代码

```java
class Solution {
    public String removeStars(String s) {
        Deque<Character> stack = new ArrayDeque<>();
        int n = s.length();

        for (int i = 0; i < n; i++) {
            char k = s.charAt(i);
            if (k == '*') {
                stack.pop();
            } else {
                stack.push(k);
            }
        }

        StringBuilder result = new StringBuilder();
        while (!stack.isEmpty()) {
            result.append(stack.pop());
        }

        return result.reverse().toString();
    }
}
```

## Stack 数据结构核心理解

```text
Stack = Last In, First Out（LIFO）

push(x)  → 把元素放到栈顶
pop()    → 删除并返回栈顶元素
peek()   → 查看栈顶但不删除
isEmpty()→ 判断栈是否为空
```

这题的识别模式：

```text
“删除最近尚未删除的字符”
→ 最近加入、最先处理
→ Stack
```

Java 中虽然存在旧的 `java.util.Stack` 类，但新代码更常使用：

```java
Deque<Character> stack = new ArrayDeque<>();
```

其中：

- `Deque` 是接口；
- `ArrayDeque` 是具体实现类；
- 变量名 `stack` 只是说明这里把 `Deque` 当作 Stack 使用。

## JVM Stack / Heap 与数据结构 Stack / Heap

今天顺带区分了两个容易混淆的概念：

```text
JVM Stack / Heap
→ JVM 运行时内存管理概念

数据结构 Stack / Heap
→ 算法中组织和访问数据的规则
```

当前阶段只需掌握 JVM Stack 的基础心智模型：

- 每个线程有自己的 JVM Stack；
- 每次方法调用会建立一个 Stack Frame；
- Stack Frame 保存局部变量、参数、中间计算和方法执行信息；
- 方法返回时对应 frame 结束；
- 递归太深可能导致 `StackOverflowError`；
- 局部引用可以指向 Heap 中的对象；
- JVM 内存里的 Stack 与本题的 Stack 数据结构不是同一个概念。

## 调试记录

### 1. 字符常量需要单引号

错误：

```java
if (k == *)
```

正确：

```java
if (k == '*')
```

### 2. `else` 使用花括号

错误地把代码块写成圆括号会造成连锁编译错误。

### 3. 返回类型不匹配

方法要求：

```java
public String removeStars(String s)
```

所以不能：

```java
return stack;
```

因为 `stack` 是 `Deque<Character>`，最终必须转换为 `String`。
