### 为什么记为 B

最初对 `first`、`second` 的含义没有头绪，并重点讨论了以下情况：

```text
[1,2,3,0]
[1,2,0,3]
```

在提示后理解：

- `first` 为未来保存尽可能小的起点；
- `second` 证明历史上已经出现过一个合法递增二元组；
- 后来更新 `first` 不会使已有的 `second` 失效；
- 当前数字大于 `second` 时，已经存在递增三元组。

实现由自己写出并通过，但核心贪心状态由提示引导，因此暂记 B。之后闭卷重写并能独立解释变量不变量后再提高等级。

## 最终 Accepted 代码

```java
class Solution {
    public boolean increasingTriplet(int[] nums) {
        int first = Integer.MAX_VALUE;
        int second = Integer.MAX_VALUE;

        for (int k : nums) {
            if (k < first) {
                first = k;
            } else if (first < k && k < second) {
                second = k;
            } else if (k > second) {
                return true;
            }
        }

        return false;
    }
}
```

## 核心状态

```text
first：目前最适合作为第一个数的值
second：目前最小的合法第二个数
当前 k > second：找到第三个数，立即返回 true
```

示例：

```text
[1,2,0,3]

1 → first = 1
2 → second = 2，历史上存在 1 < 2
0 → first = 0，为未来准备更小起点
3 → 3 > second，使用历史上的 1 < 2，得到 1 < 2 < 3
```

## Reviewer 点评

当前写法正确并已通过全部测试。可以进一步简化为标准形式：

```java
if (k <= first) {
    first = k;
} else if (k <= second) {
    second = k;
} else {
    return true;
}
```

当前代码中的 `first < k` 是显式表达条件；标准写法利用 `else if` 已经排除了较小情况，更简洁。两种写法都要求相等数字不能被当成严格递增。

# 任务 B｜1137. N-th Tribonacci Number

[打开题目](https://leetcode.com/problems/n-th-tribonacci-number/)

## 完成结果

- **难度：** Easy
- **结果：** Accepted，38 / 38
- **提交记录：** 0 ms、42.30 MB；单次排名仅作参考
- **主题：** 一维动态规划、递推、`ArrayList`
- **时间复杂度：** `O(n)`
- **额外空间：** `O(n)`
- **掌握等级：** B+

## 最终 Accepted 代码

```java
class Solution {
    public int tribonacci(int n) {
        ArrayList<Integer> list = new ArrayList<>();
        list.add(0);
        list.add(1);
        list.add(1);

        for (int i = 3; i <= n; i++) {
            list.add(list.get(i - 3) + list.get(i - 2) + list.get(i - 1));
        }

        return list.get(n);
    }
}
```

## 核心思路

题目给出的递推关系是：

```text
T(n) = T(n-1) + T(n-2) + T(n-3)
```

先将三项初始值放入列表：

```text
T0 = 0
T1 = 1
T2 = 1
```

然后从 `i = 3` 开始，按下标读取前面三项并将新结果加入列表。循环结束后，`list.get(n)` 就是答案。

## Reviewer 点评

这版代码逻辑直接、下标对应清晰，而且不需要分别处理 `n = 0、1、2`：因为三项初始值已经在列表里，循环会自然跳过，最后直接读取对应下标。

当前写法保存了从 `T0` 到 `Tn` 的所有结果，所以空间复杂度是 `O(n)`。但计算下一项实际上只需要最近三项，因此后续可以使用三个滚动变量：

```java
int a = 0;
int b = 1;
int c = 1;

for (int i = 3; i <= n; i++) {
    int next = a + b + c;
    a = b;
    b = c;
    c = next;
}
```

这样可以将额外空间降到 `O(1)`。不过当前 `ArrayList` 解法已经正确完成题目，滚动变量作为复习优化，不影响本次 Accepted。
