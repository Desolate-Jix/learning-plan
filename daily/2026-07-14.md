# 任务 A：Merge Strings Alternately 优化复刷

## 结果

- 题目：[1768. Merge Strings Alternately](https://leetcode.com/problems/merge-strings-alternately/)
- 结果：优化版本 Accepted
- 这次属于 Day 1 复刷，不重复计入新题数量

## 自己最终通过的代码

```java
class Solution {
    public String mergeAlternately(String word1, String word2) {
        StringBuilder str = new StringBuilder();
        int l1 = word1.length();
        int l2 = word2.length();
        int i = 0;

        for (i = 0; i < l1 && i < l2; i++) {
            str.append(word1.charAt(i));
            str.append(word2.charAt(i));
        }

        if (l1 > l2) {
            str.append(word1.substring(i, l1));
        }

        if (l1 < l2) {
            str.append(word2.substring(i, l2));
        }

        return str.toString();
    }
}
```

## 出现的语法与理解问题

| 写法或问题 | 原因 | 正确理解 |
|---|---|---|
| `New StringBuilder` | Java 关键字区分大小写 | 使用小写 `new` |
| `new StringBuilder` | 创建对象时漏掉构造函数括号 | `new StringBuilder()` |
| `reached end of file while parsing` | `{` 与 `}` 没有配对 | 方法和类都需要结束大括号 |
| 在 `for (int i = ...)` 后继续使用 `i` | `i` 只在该循环代码块内存在 | 在循环前声明 `int i = 0;` |
| `substring(i, l1 - 1)` | 误以为结束下标会被包含 | `substring` 结束位置不包含，应传 `l1` |

## `substring` 规则

```java
String word = "abcdef";
word.substring(1, 4); // "bcd"
```

范围是：

```text
[start, end)
包含 start，不包含 end
```

因此：

```java
word.substring(2, 4); // "cd"
word.substring(2);    // 从下标 2 一直到结尾
```

## Reviewer 点评

### 做得好的地方

- 把两个同步下标简化成一个 `i`；
- 使用 `StringBuilder.append()`；
- 能正确保留主循环结束后的 `i`；
- 理解 `substring` 的右边界不包含；
- 能从空白重新写出优化版并通过。

### 可以改进

- `str` 可以改为 `result`；
- 这里用 `while` 会比已有初始化的 `for` 更自然；
- 两个 `if` 可以省略，因为无剩余字符时 `substring(i)` 返回空字符串；
- 可以给 `StringBuilder` 预分配最终容量。

## 推荐版本

```java
class Solution {
    public String mergeAlternately(String word1, String word2) {
        int i = 0;
        int length1 = word1.length();
        int length2 = word2.length();

        StringBuilder result = new StringBuilder(length1 + length2);

        while (i < length1 && i < length2) {
            result.append(word1.charAt(i));
            result.append(word2.charAt(i));
            i++;
        }

        result.append(word1.substring(i));
        result.append(word2.substring(i));

        return result.toString();
    }
}
```

- 时间复杂度：`O(n + m)`
- 结果空间：`O(n + m)`

# 任务 B：Kids With the Greatest Number of Candies

## 结果

- 题目：[1431. Kids With the Greatest Number of Candies](https://leetcode.com/problems/kids-with-the-greatest-number-of-candies/)
- 结果：Accepted
- 掌握等级：B

自己的核心算法：

1. 第一遍扫描数组，找出当前最大糖果数；
2. 第二遍扫描，判断每个孩子加上额外糖果后是否达到或超过最大值；
3. 把每个判断结果加入 `List<Boolean>`。

## 自己最终通过的代码

```java
class Solution {
    public List<Boolean> kidsWithCandies(int[] candies, int extraCandies) {
        int i = candies.length;
        int maxchild = 0;

        for (int a = 0; a < i; a++) {
            if (candies[a] > maxchild) {
                maxchild = candies[a];
            }
        }

        List<Boolean> candy = new ArrayList<>();

        for (int b = 0; b < i; b++) {
            if (candies[b] + extraCandies >= maxchild) {
                candy.add(true);
            } else {
                candy.add(false);
            }
        }

        return candy;
    }
}
```

## 今日 Java 知识：数组与 List

### 数组

```java
int[] nums = new int[5];
nums[0] = 10;
int value = nums[0];
int length = nums.length;
```

- 长度创建后固定；
- 使用 `[]` 读取和修改；
- 使用 `.length` 获取长度。

### List / ArrayList

```java
List<Boolean> result = new ArrayList<>();
result.add(true);
Boolean value = result.get(0);
result.set(0, false);
int size = result.size();
```

- 可以用 `add()` 不断增加元素；
- 使用 `get()` 和 `set()`，不能使用数组的 `[]`；
- 使用 `size()` 获取元素数量；
- `List` 是接口，`ArrayList` 是常用实现。

### `boolean` 与 `Boolean`

泛型只能使用引用类型：

```java
List<Boolean> values; // 正确
List<boolean> values; // 错误

List<Integer> nums;   // 正确
List<int> nums;       // 错误
```

Java 会自动在 `boolean` 和 `Boolean` 之间装箱、拆箱：

```java
result.add(true);
```

## 本题出现的错误

| 当时写法 / 问题 | 原因 | 正确写法 |
|---|---|---|
| `boolean candy[];` | 只声明数组且没有长度；方法还要求返回 List | `List<Boolean> candy = new ArrayList<>();` |
| `return candy[];` | 返回表达式后不能写 `[]` | `return candy;` |
| `if (candies[a] maxchild)` | 漏掉比较运算符 | `if (candies[a] > maxchild)` |
| `list<boolean>` | 类名大小写错误；泛型不能使用基本类型 | `List<Boolean>` |
| `Arraylist` | `L` 必须大写 | `ArrayList` |
| `new ArrayList<>` | 创建对象漏写构造函数括号 | `new ArrayList<>()` |
| `candy[b] = true` | 把 List 当成数组；空 List 中还没有该位置 | `candy.add(true)` |

## 两遍线性扫描

```text
第一遍 O(n)：找最大值
第二遍 O(n)：生成结果
```

```text
O(n) + O(n) = O(2n) = O(n)
```

大 O 忽略常数系数。

- 时间复杂度：`O(n)`
- 输出空间：`O(n)`
- 除输出外额外空间：`O(1)`

## Reviewer 点评

### 做得好的地方

- 只寻找一次最大值，没有对每个孩子重复寻找；
- 正确使用 `>=` 处理并列最大；
- 把问题拆成“建立比较基准”和“生成结果”；
- 学会使用 `List<Boolean>` 和 `add()`。

### 可以改进

变量名可改为：

```java
int length = candies.length;
int maxCandies = candies[0];
List<Boolean> result = new ArrayList<>(length);
```

比较表达式本身已经是布尔值：

```java
result.add(candies[b] + extraCandies >= maxCandies);
```

## 推荐版本

```java
class Solution {
    public List<Boolean> kidsWithCandies(int[] candies, int extraCandies) {
        int maxCandies = candies[0];

        for (int candy : candies) {
            maxCandies = Math.max(maxCandies, candy);
        }

        List<Boolean> result = new ArrayList<>(candies.length);

        for (int candy : candies) {
            result.add(candy + extraCandies >= maxCandies);
        }

        return result;
    }
}
```

新增但暂不要求背诵：

- 增强 `for`：`for (int candy : candies)`；
- `Math.max(a, b)`。

# 任务 C：Can Place Flowers

## 结果

- 题目：[605. Can Place Flowers](https://leetcode.com/problems/can-place-flowers/)
- 结果：Accepted，130 / 130
- 掌握等级：B
- 最终思路：分别处理长度为 1、首位、中间和末位；每次种花后立即更新数组状态

## 自己最终通过的代码

```java
class Solution {
    public boolean canPlaceFlowers(int[] flowerbed, int n) {
        int l = flowerbed.length;
        int counter = 0;

        if (l == 1 && flowerbed[0] == 0) {
            counter++;
        }

        if (l > 1) {
            if (flowerbed[0] == 0 && flowerbed[1] == 0) {
                counter++;
                flowerbed[0] = 1;
            }

            for (int i = 1; i < l - 1; i++) {
                if (flowerbed[i - 1] == 0
                        && flowerbed[i] == 0
                        && flowerbed[i + 1] == 0) {
                    flowerbed[i] = 1;
                    counter++;
                }
            }

            if (flowerbed[l - 1] == 0 && flowerbed[l - 2] == 0) {
                flowerbed[l - 1] = 1;
                counter++;
            }
        }

        return n <= counter;
    }
}
```

> 只统一了缩进，保留实际 Accepted 的逻辑。

## 调试过程

```text
只按总长度和已有花数量计算
→ Wrong Answer

拼写、比较运算符错误
→ Compile Error

循环访问 i + 1 到达数组外
→ Runtime Error

if 没有大括号，counter++ 每次都执行
→ Wrong Answer

补齐长度为 1、首尾边界和代码块
→ Accepted 130 / 130
```

## 错误记录

| 问题 | 根本原因 | 修正方式 |
|---|---|---|
| 用长度和已有花数量推算最大可种数 | 能否种取决于 `0/1` 的排列位置 | 逐个位置检查左、当前、右 |
| 问“怎么除 2 不取余数”并尝试公式 | Java 整数除法会截断小数，但该题不能仅靠长度公式 | 用局部邻居判断，不依赖总长度公式 |
| `f;powerbed` | 变量名拼错并插入分号 | `flowerbed` |
| `flowerbed[i] = 0` | `=` 是赋值，不是比较 | `flowerbed[i] == 0` |
| `Index 7 out of bounds for length 7` | `i` 到最后一位后仍访问 `i + 1` | 中间循环限定 `i < l - 1` |
| 长度为 1 时访问 `flowerbed[1]` | 数组只有下标 0 | 单独处理 `l == 1` |
| `counter++` 条件不成立也执行 | `if` 没有 `{}`，只控制下一条语句 | 用大括号包住修改和计数 |

## 今日 Java 知识

### 1. 整数除法

```java
int value = 5 / 2; // 2
```

两个操作数都是整数时，小数部分会被截断。

```java
double value = 5.0 / 2; // 2.5
```

但本题的错误不在除法语法，而在于“可种数量取决于具体排列”。

### 2. 数组边界

数组长度为 `l`：

```text
合法下标：0 到 l - 1
```

访问 `i + 1` 时必须保证：

```java
i < l - 1
```

访问 `i - 1` 时必须保证：

```java
i > 0
```

### 3. `=` 与 `==`

```java
flowerbed[i] = 1;   // 赋值：修改数组
flowerbed[i] == 0;  // 比较：产生 true / false
```

### 4. Java 不看缩进，只看大括号

```java
if (condition)
    action1();
action2();
```

只有 `action1()` 受条件控制。

```java
if (condition) {
    action1();
    action2();
}
```

两条语句都受条件控制。

### 5. 做出选择后立即更新状态

```java
flowerbed[i] = 1;
```

这样检查下一个位置时，能够看到刚刚已经种下的花，避免在相邻位置重复种植。

## Reviewer 点评

### 做得好的地方

- 根据反例放弃错误的总数量公式；
- 能区分首位、中间、末位；
- 从 Runtime Error 中理解了 `i + 1` 的边界；
- 理解缺少大括号为何导致错误计数；
- 补上长度为 1 的特殊情况；
- 最终通过全部 130 个测试。

### 可以改进

当前写法正确，但分支较多。可以统一为一个循环：

```java
boolean leftEmpty = i == 0 || flowerbed[i - 1] == 0;
boolean rightEmpty = i == flowerbed.length - 1 || flowerbed[i + 1] == 0;
```

然后判断：

```java
if (flowerbed[i] == 0 && leftEmpty && rightEmpty) {
    flowerbed[i] = 1;
    planted++;
}
```

## 推荐单循环版本

```java
class Solution {
    public boolean canPlaceFlowers(int[] flowerbed, int n) {
        int planted = 0;

        for (int i = 0; i < flowerbed.length; i++) {
            boolean leftEmpty = i == 0 || flowerbed[i - 1] == 0;
            boolean rightEmpty = i == flowerbed.length - 1 || flowerbed[i + 1] == 0;

            if (flowerbed[i] == 0 && leftEmpty && rightEmpty) {
                flowerbed[i] = 1;
                planted++;

                if (planted >= n) {
                    return true;
                }
            }
        }

        return planted >= n;
    }
}
```

- 时间复杂度：`O(n)`
- 额外空间：`O(1)`
