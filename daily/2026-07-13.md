## 自己最终 Accepted 的代码

```java
class Solution {
    public String mergeAlternately(String word1, String word2) {
        int a = 0;
        int b = 0;
        String word = "";

        if (a <= word1.length() && b <= word2.length()) {
            for (a = 0, b = 0;
                 a <= word1.length() - 1 && b <= word2.length() - 1;
                 a++, b++) {
                word = word + word1.charAt(a) + word2.charAt(b);
            }

            if (word1.length() > word2.length()) {
                for (int n = word1.length() - word2.length();
                     n > 0;
                     n--, a++) {
                    word = word + word1.charAt(a);
                }
            }

            if (word2.length() > word1.length()) {
                for (int n = word2.length() - word1.length();
                     n > 0;
                     n--, b++) {
                    word = word + word2.charAt(b);
                }
            }
        }

        return word;
    }
}
```

## 今日 Java 知识

### 1. 变量声明、初始化和重新赋值

```java
int a = 0;
String word = "";
```

表示创建变量并给初始值。

```java
a = 1;
word = word + "a";
```

表示变量已经存在，现在更新其值。

下面错误：

```java
String word = word + "a";
```

Java 会先计算右边，但此时 `word` 还没有完成初始化。

正确：

```java
String word = "";
word = word + "a";
```

### 2. `=` 与比较运算符

```java
int a = 0;                 // 赋值
a < word1.length();        // 比较，结果为 true 或 false
```

下面不是合法变量声明：

```java
int a <= word1.length();
```

### 3. `if`、`for` 和 `while`

#### `if`：判断一次

```java
if (word1.length() > word2.length()) {
    System.out.println("word1 更长");
}
```

#### `for`：按明确规律重复

```java
for (int i = 0; i < word.length(); i++) {
    System.out.println(word.charAt(i));
}
```

格式固定为：

```java
for (初始化; 继续条件; 每轮更新) {
    循环体;
}
```

#### `while`：条件成立期间持续重复

```java
while (i < word1.length() && i < word2.length()) {
    i++;
}
```

一句话区分：

- `if`：要不要做一次；
- `for` / `while`：要不要继续重复做。

### 4. `&&` 与 `||`

```java
a < word1.length() && b < word2.length()
```

`&&` 表示两边都必须成立。

```java
a < word1.length() || b < word2.length()
```

`||` 表示至少一边成立。

### 5. String 与数组的长度

```java
word.length(); // String：方法，有括号
nums.length;   // 数组：字段，没有括号
```

### 6. 下标边界

字符串：

```text
word = "abc"
长度 = 3
合法下标 = 0、1、2
```

因此通常写：

```java
i < word.length()
```

而不是：

```java
i <= word.length()
```

### 7. `charAt(i)`

```java
String word = "abc";
char first = word.charAt(0);  // 'a'
```

返回类型是 `char`。

### 8. `return`

方法声明：

```java
public String mergeAlternately(...)
```

表示方法必须返回一个 `String`：

```java
return word;
```

没有返回值会出现：

```text
missing return statement
```

### 9. String 拼接与 StringBuilder

字符串拼接可以写：

```java
String result = "";
result = result + "a";
```

但 `String` 不可修改，循环里反复 `+` 会不断创建并复制新字符串。

更适合循环拼接：

```java
StringBuilder result = new StringBuilder();
result.append('a');
return result.toString();
```

### 10. `substring(start, end)`

范围规则：

```text
[start, end)
包含开始，不包含结束
```

```java
String word = "abcdef";
word.substring(1, 4); // "bcd"
```

## 当天语法错误记录

| 当时写法 / 报错 | 原因 | 正确或推荐写法 |
|---|---|---|
| `int a <= word1.length;` | 声明变量时错误使用比较符；String 长度还漏括号 | `int a = 0;`，比较放进条件：`a < word1.length()` |
| `word1.length` | String 使用 `length()` 方法 | `word1.length()` |
| `a <= word1.length()` | 当 `a == length()` 时再 `charAt(a)` 会越界 | `a < word1.length()` |
| 条件中使用逗号 | 循环条件最终必须是一个布尔表达式 | 使用 `&&` 或 `||` |
| `chatAt(a)` | 方法名拼写错误 | `charAt(a)` |
| `String word = word + ...` | 右侧读取尚未初始化的变量 | 先 `String word = "";` |
| 漏写 `;` | Java 普通语句通常以分号结束 | 在赋值语句末尾加 `;` |
| 缺少 `return` | 方法承诺返回 String | `return word;` |
| 外层 `if` 包住整个循环 | 不一定报错，但逻辑冗余 | 让循环自身负责继续条件 |

### 报错含义

```text
';' expected
```

通常表示当前行或上一行漏写分号。

```text
not a statement
```

表示某段代码不能构成合法 Java 语句。

```text
cannot find symbol
```

常见原因：拼写错误、漏括号、变量尚未声明。

```text
missing return statement
```

表示有返回类型的方法没有在所有执行路径返回结果。

## 推荐改进版本

```java
class Solution {
    public String mergeAlternately(String word1, String word2) {
        int i = 0;
        int length1 = word1.length();
        int length2 = word2.length();

        StringBuilder result = new StringBuilder(length1 + length2);

        while (i < length1 && i < length2) {
            result.append(word1.charAt(i));
            result.append(word2.charAt(i));
            i++;
        }

        result.append(word1.substring(i));
        result.append(word2.substring(i));

        return result.toString();
    }
}
```

- 时间复杂度：`O(n + m)`
- 结果空间：`O(n + m)`
