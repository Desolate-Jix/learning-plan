## 1. 双指针的基本思路

假设：

```text
s = "abc"
t = "ahbgdc"
```

准备两个下标：

```text
i：指向 s 当前等待匹配的字符
j：指向 t 当前正在检查的字符
```

规则：

1. 如果 `s.charAt(i) == t.charAt(j)`，说明当前字符匹配成功，`i++`；
2. 无论是否匹配，`j` 都继续向后扫描；
3. 当 `i == s.length()`，说明 `s` 的每个字符都按顺序在 `t` 中找到。

示例过程：

| 步骤 | `i` 指向 | `j` 指向 | 是否相同 | 移动方式 |
|---|---|---|---|---|
| 1 | `a` | `a` | 是 | `i++`、`j++` |
| 2 | `b` | `h` | 否 | 只 `j++` |
| 3 | `b` | `b` | 是 | `i++`、`j++` |
| 4 | `c` | `g` | 否 | 只 `j++` |
| 5 | `c` | `d` | 否 | 只 `j++` |
| 6 | `c` | `c` | 是 | `i++`、`j++` |

## 2. 今日 Java 知识

### 2.1 读取字符串第几个字符

```java
String word = "hello";

word.charAt(0); // 'h'
word.charAt(1); // 'e'
word.charAt(4); // 'o'
```

字符串下标从 `0` 开始。长度为 `n` 时，合法下标是：

```text
0 到 n - 1
```

调用 `charAt(index)` 前必须保证：

```java
0 <= index && index < word.length()
```

### 2.2 在一个 `for` 中声明两个同类型变量

错误写法：

```java
for (int i = 0, int j = 0; ...)
```

正确写法：

```java
for (int i = 0, j = 0; ...)
```

类型 `int` 只写一次，后面的同类型变量用逗号继续声明。

### 2.3 Java 和 C++ 不要混用

今天一度把编辑器切成了 C++。两种语言的部分写法不同：

```text
Java：String、boolean、charAt()
C++：string、bool、下标访问字符串
```

本计划统一使用 Java。每次开始前先确认编辑器左上角为 `Java`。

## 3. 第一版代码与算法方向

第一版结构：

```java
int sl = s.length();
int tl = t.length();
int counter = 0;

for (int i = 0, j = 0; j < tl; j++) {
    if (s.charAt(i) == t.charAt(j)) {
        counter++;
        i++;
    }
}

return counter == sl;
```

算法方向正确：

- `j` 从左到右扫描 `t`；
- 找到匹配字符时才移动 `i`；
- `counter` 统计成功匹配的字符数。

问题不在双指针思路，而在没有完整保护 `s.charAt(i)` 的下标。

## 4. 今日错误与调试过程

### 4.1 一度比较了错误的字符串

曾写成：

```java
s.charAt(i) == s.charAt(j)
```

但题目需要比较：

```java
s.charAt(i) == t.charAt(j)
```

因为 `i` 指向 `s`，`j` 指向 `t`。

### 4.2 为什么 Testcase 可以通过，Submit 却报错

右侧 **Testcase / Run** 只运行当前显示或手动添加的少量样例，例如：

```text
s = "abc"
t = "ahbgdc"
```

这些样例没有覆盖所有边界。

点击 **Submit** 后，会运行全部隐藏测试，包括：

```text
s = ""
t = "ahbgdc"
```

以及：

```text
s = "b"
t = "abc"
```

因此：

> 本地样例通过不等于整道题完成；只有 Submit 通过全部隐藏测试才算正式 Accepted。

### 4.3 Runtime Error 1：空字符串

错误：

```text
StringIndexOutOfBoundsException: Index 0 out of bounds for length 0
```

失败输入：

```text
s = ""
t = "ahbgdc"
```

空字符串长度为 `0`，不存在下标 `0`，所以：

```java
s.charAt(0)
```

会越界。

用户先加入：

```java
if (sl == 0) {
    return true;
}
```

这能处理空字符串，但还不能处理“已经匹配完成后仍继续读取”的情况。

### 4.4 Runtime Error 2：匹配完成后循环仍继续

失败输入：

```text
s = "b"
t = "abc"
```

执行过程：

```text
初始：i = 0，j = 0

t[0] = 'a'，与 s[0] = 'b' 不同
j 变成 1

t[1] = 'b'，与 s[0] = 'b' 相同
i 变成 1，counter 变成 1

下一轮 j = 2
循环仍然继续，尝试读取 s.charAt(1)
```

但 `s` 长度为 `1`，合法下标只有 `0`，因此出现：

```text
Index 1 out of bounds for length 1
```

### 4.5 用户独立找到的最终修复

用户自己把循环条件改成：

```java
j < tl && i < sl
```

这同时保护：

```java
t.charAt(j)
s.charAt(i)
```

当 `s` 已经匹配完成时，`i < sl` 为 `false`，循环立即停止，不再访问不存在的下标。

这是今天最重要的独立调试成果。

## 5. 用户最终 Accepted 的代码

```java
class Solution {
    public boolean isSubsequence(String s, String t) {
        int sl = s.length();
        int tl = t.length();
        int counter = 0;

        if (sl == 0) {
            return true;
        } else {
            for (int i = 0, j = 0; j < tl && i < sl; j++) {
                if (s.charAt(i) == t.charAt(j)) {
                    counter++;
                    i++;
                }
            }
        }

        if (counter == sl) {
            return true;
        } else {
            return false;
        }
    }
}
```

> 上面只统一了缩进，保留实际通过 22 / 22 测试的逻辑。

4. 最终独立发现 `i < sl` 也必须放进循环条件；

6. 在疲劳状态下仍完成了当天唯一任务，没有强行追加第二题。

### 可以改进的地方

#### 1. `counter` 和 `i` 表达重复信息

每次匹配成功时：

```java
counter++;
i++;
```

两者始终同步，因此：

```text
i = 已成功匹配的字符数量
```

可以只保留 `i`。

#### 2. 空字符串不需要单独 `if`

如果循环条件本身包含：

```java
i < s.length()
```

那么 `s` 为空时循环自然不执行，最后：

```java
return i == s.length();
```

会得到 `0 == 0`，自动返回 `true`。

#### 3. 返回布尔值不需要完整 `if / else`

当前：

```java
if (counter == sl) {
    return true;
} else {
    return false;
}
```

可以直接写：

```java
return counter == sl;
```

## 7. 推荐简化版本

```java
class Solution {
    public boolean isSubsequence(String s, String t) {
        int i = 0;

        for (int j = 0; j < t.length() && i < s.length(); j++) {
            if (s.charAt(i) == t.charAt(j)) {
                i++;
            }
        }

        return i == s.length();
    }
}
```

这不是不同算法，只是删掉了重复状态和不必要分支。

## 8. 复杂度

假设：

```text
m = s.length()
n = t.length()
```

- `j` 最多遍历 `t` 一次；
- 时间复杂度：`O(n)`；
- 只使用少量整数变量；
- 额外空间复杂度：`O(1)`。
