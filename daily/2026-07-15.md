## 先理解“双指针”

假设：

```text
s = "abc"
t = "ahbgdc"
```

可以准备两个下标：

```text
i：指向 s 当前等待匹配的字符
j：指向 t 当前正在检查的字符
```

思考规则：

1. 如果 `s.charAt(i)` 和 `t.charAt(j)` 相同，说明找到了一个字符；
2. 找到后，`i` 和 `j` 都向后移动；
3. 如果不同，只让 `j` 向后寻找；
4. 当 `i` 到达 `s.length()`，说明 `s` 的全部字符都按顺序找到了。

| 步骤 | `i` 指向 | `j` 指向 | 是否相同 | 怎么移动 |
|---|---|---|---|---|
| 1 | `a` | `a` | 是 | `i++`、`j++` |
| 2 | `b` | `h` | 否 | 只 `j++` |
| 3 | `b` | `b` | 是 | `i++`、`j++` |
| 4 | `c` | `g` | 否 | 只 `j++` |
| 5 | `c` | `d` | 否 | 只 `j++` |
| 6 | `c` | `c` | 是 | `i++`、`j++` |

## 第一版代码思路

当前第一版使用：

```java
int sl = s.length();
int tl = t.length();
int counter = 0;

for (int i = 0, j = 0; j < tl; j++) {
    if (s.charAt(i) == t.charAt(j)) {
        counter++;
        i++;
    }
}

return counter == sl;
```

算法方向基本正确：`j` 扫描 `t`，匹配成功后移动 `i`。

## 当前 Runtime Error

报错：

```text
StringIndexOutOfBoundsException: Index 0 out of bounds for length 0
```

失败输入：

```text
s = ""
t = "ahbgdc"
```

### 根本原因 1：空字符串没有下标 0

当：

```java
s.length() == 0
```

字符串中没有任何字符，因此：

```java
s.charAt(0)
```

会直接越界。

### 根本原因 2：匹配完成后仍可能继续读取 `s`

即使 `s` 不为空，当 `i == s.length()` 时，已经匹配完全部字符。如果循环继续执行：

```java
s.charAt(i)
```

同样会访问不存在的下标 `length()`。

## 正确的边界条件

在调用：

```java
s.charAt(i)
```

之前，必须保证：

```java
i < s.length()
```

推荐把 `i` 放在循环外，以便循环结束后直接判断：

```java
int i = 0;

for (int j = 0; j < t.length() && i < s.length(); j++) {
    if (s.charAt(i) == t.charAt(j)) {
        i++;
    }
}

return i == s.length();
```

这个结构自动处理：

- `s` 是空字符串：`i < s.length()` 一开始就是 `false`，不会调用 `charAt(0)`；
- 已经匹配完 `s`：循环立即停止，不会继续越界；
- `counter` 不再需要，因为 `i` 本身就表示已经匹配了多少个字符。

## 今天新增的知识点

### 1. 任何 `charAt(i)` 前都要确认下标合法

```java
0 <= i && i < word.length()
```

### 2. 空字符串是合法输入

```java
String s = "";
s.length(); // 0
```

空字符串是任何字符串的子序列，因此本题应返回 `true`。

### 3. 指针本身可以代替计数器

在本题中：

```text
i = 已经匹配成功的字符数量
```

所以不需要同时维护：

```java
counter
```

两个变量表达同一件事会增加出错机会。
