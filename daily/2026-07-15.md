
## 先理解“双指针”

假设：

```text
s = "abc"
t = "ahbgdc"
```

可以准备两个下标：

```text
i：指向 s 当前等待匹配的字符
j：指向 t 当前正在检查的字符
```

思考规则：

1. 如果 `s.charAt(i)` 和 `t.charAt(j)` 相同，说明找到了一个字符；
2. 找到后，`i` 和 `j` 都向后移动；
3. 如果不同，只让 `j` 向后寻找；
4. 当 `i` 到达 `s.length()`，说明 `s` 的全部字符都按顺序找到了。

| 步骤 | `i` 指向 | `j` 指向 | 是否相同 | 怎么移动 |
|---|---|---|---|---|
| 1 | `a` | `a` | 是 | `i++`、`j++` |
| 2 | `b` | `h` | 否 | 只 `j++` |
| 3 | `b` | `b` | 是 | `i++`、`j++` |
| 4 | `c` | `g` | 否 | 只 `j++` |
| 5 | `c` | `d` | 否 | 只 `j++` |
| 6 | `c` | `c` | 是 | `i++`、`j++` |

## 第一版代码思路

当前第一版使用：

```java
int sl = s.length();
int tl = t.length();
int counter = 0;

for (int i = 0, j = 0; j < tl; j++) {
    if (s.charAt(i) == t.charAt(j)) {
        counter++;
        i++;
    }
}

return counter == sl;
```

算法方向基本正确：`j` 扫描 `t`，匹配成功后移动 `i`。

## Runtime Error 1：空字符串

报错：

```text
StringIndexOutOfBoundsException: Index 0 out of bounds for length 0
```

失败输入：

```text
s = ""
t = "ahbgdc"
```

### 根本原因

当 `s.length() == 0` 时，字符串中没有下标 `0`，因此：

```java
s.charAt(0)
```

会直接越界。

用户随后加入：

```java
if (sl == 0) {
    return true;
}
```

这解决了空字符串输入，但还没有解决“匹配完以后继续访问”的问题。

## Runtime Error 2：匹配完成后循环没有停止

失败输入：

```text
s = "b"
t = "abc"
```

错误信息：

```text
StringIndexOutOfBoundsException: Index 1 out of bounds for length 1
```

逐步执行：

```text
初始：i = 0，j = 0

t[0] = 'a'，与 s[0] = 'b' 不同
j 变成 1

t[1] = 'b'，与 s[0] = 'b' 相同
i 变成 1，counter 变成 1

下一轮 j = 2，循环仍然继续
代码尝试访问 s.charAt(1)
```

但是 `s` 的长度为 `1`，合法下标只有 `0`。下标 `1` 已经越界。

### 根本原因

循环条件只有：

```java
j < t.length()
```

它只保护了 `t.charAt(j)`，没有保护：

```java
s.charAt(i)
```

因此每次读取 `s.charAt(i)` 前，还必须满足：

```java
i < s.length()
```

## 正确的边界条件

最小修改是：

```java
for (int i = 0, j = 0; j < tl && i < sl; j++) {
    if (s.charAt(i) == t.charAt(j)) {
        counter++;
        i++;
    }
}
```

`&&` 具有短路特性：只要 `j < tl` 或 `i < sl` 中任意一个为 `false`，循环就不会继续，也不会执行 `charAt()`。

更清楚的结构是把 `i` 放在循环外：

```java
int i = 0;

for (int j = 0; j < t.length() && i < s.length(); j++) {
    if (s.charAt(i) == t.charAt(j)) {
        i++;
    }
}

return i == s.length();
```

这个结构自动处理：

- `s` 是空字符串：`i < s.length()` 一开始就是 `false`；
- 已经匹配完 `s`：循环立即停止；
- `counter` 不再需要，因为 `i` 本身就是已经匹配成功的字符数量。

## 今天新增的知识点

### 1. 每个下标都需要独立保护

调用：

```java
s.charAt(i)
t.charAt(j)
```

之前分别需要保证：

```java
i < s.length()
j < t.length()
```

只检查一个字符串的边界，不能保护另一个字符串。

### 2. 任何 `charAt(i)` 前都要确认下标合法

```java
0 <= i && i < word.length()
```

### 3. 空字符串是合法输入

```java
String s = "";
s.length(); // 0
```

空字符串是任何字符串的子序列，因此本题应返回 `true`。

### 4. 指针本身可以代替计数器

在本题中：

```text
i = 已经匹配成功的字符数量
```

所以不需要同时维护 `counter`。两个变量表达同一件事会增加出错机会。
