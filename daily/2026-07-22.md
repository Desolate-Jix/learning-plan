## 2. 自己最终 Accepted 的代码

```java
class Solution {
    public String gcdOfStrings(String str1, String str2) {
        StringBuilder sb = new StringBuilder();
        int n1 = str1.length();
        int n2 = str2.length();

        for (int i = 0; i < n1 && i < n2; i++) {
            if (str1.charAt(i) == str2.charAt(i)) {
                sb.append(str1.charAt(i));
            } else {
                break;
            }
        }

        String candidate = sb.toString();
        int k = candidate.length();

        for (int i = candidate.length(); i > 0; i--) {
            if (checkcandidate(str1, candidate)
                    && checkcandidate(str2, candidate)) {
                return candidate;
            } else {
                candidate = candidate.substring(
                    0,
                    candidate.length() - 1
                );
            }
        }

        return "";
    }

    public boolean checkcandidate(String str, String candidate) {
        int n1 = str.length();
        int n2 = candidate.length();

        if (candidate.length() == 0) {
            return false;
        } else {
            if (n1 % n2 == 0) {
                int k = n1 / n2;
                int counter = 0;

                for (int i = 0; i < n1; i = i + n2) {
                    if (str.substring(i, i + n2).equals(candidate)) {
                        counter++;
                    }
                }

                if (counter == k) {
                    return true;
                } else {
                    return false;
                }
            } else {
                return false;
            }
        }
    }
}
```

> 上面只整理了缩进，保留实际提交通过的算法结构。

## 3. 最终算法思路

### 第一步：找两个字符串的最长公共前缀

例如：

```text
str1 = "ABABAB"
str2 = "ABAB"
```

逐字符比较后得到：

```text
candidate = "ABAB"
```

答案一定是两个字符串共同拥有的前缀，因此不必从字符串中间寻找候选。

### 第二步：从最长候选开始逐渐删除最后一个字符

检查顺序：

```text
"ABAB"
"ABA"
"AB"
"A"
```

每次都回到两个原字符串，检查当前候选能不能重复铺满它们：

```java
checkcandidate(str1, candidate)
checkcandidate(str2, candidate)
```

第一个同时成功的候选就是最长答案。

### 第三步：检查候选能否重复组成目标字符串

例如：

```text
target = "ABABAB"
candidate = "AB"
```

先检查长度：

```text
6 % 2 == 0
```

然后按候选长度切块：

```text
"AB" | "AB" | "AB"
```

每一块都和候选 `.equals()`，所以返回 `true`。

## 4. 为什么这版能处理关键用例

### 用例 A

```text
str1 = "ABABABAB"
str2 = "ABAB"
```

最长公共前缀：

```text
"ABAB"
```

它已经可以重复组成两个字符串，因此直接返回：

```text
"ABAB"
```

### 用例 B

```text
str1 = "ABABAB"
str2 = "ABAB"
```

检查过程：

```text
"ABAB" → 不能铺满 str1
"ABA"  → 不能铺满
"AB"   → 两边都成功
```

返回：

```text
"AB"
```

### 用例 C

```text
str1 = "AAAAAA"
str2 = "AAAA"
```

检查过程：

```text
"AAAA" → 长度 6 不能被 4 整除
"AAA"  → 长度 4 不能被 3 整除
"AA"   → 两边都可以重复组成
```

返回：

```text
"AA"
```

### 用例 D

```text
str1 = "LEET"
str2 = "CODE"
```

公共前缀为空，循环不执行，最终返回：

```text
""
```

## 5. 今日字符串操作

### 字符串长度

```java
str.length()
```

### 读取单个字符

```java
str.charAt(i)
```

`charAt()` 返回 `char`，比较时使用：

```java
str1.charAt(i) == str2.charAt(i)
```

不能对 `char` 调用 `.equals()`。

### 截取字符串

```java
str.substring(start, end)
```

范围是 `[start, end)`，不包含 `end`。

删除最后一个字符：

```java
str = str.substring(0, str.length() - 1);
```

### 比较字符串内容

```java
piece.equals(candidate)
```

不要使用：

```java
piece == candidate
```

### 空字符串

```java
str.isEmpty()
```

或：

```java
str.length() == 0
```

## 6. 今日出现的错误与原因

| 问题 | 根因 | 修正 |
|---|---|---|
| `char cannot be dereferenced` | `charAt()` 返回基本类型 `char`，不能调用 `.equals()` | 字符使用 `==` 比较 |
| `StringIndexOutOfBoundsException` | 循环误写为 `1 < n2`，访问了较短字符串不存在的下标 | 改为 `i < n1 && i < n2` |
| `/ by zero` | 公共前缀为空，`candidate.length() == 0`，随后执行取余 | 先处理空候选，或让候选循环自然跳过 |
| `illegal start of expression` | `gcdOfStrings()` 少一个 `}`，辅助方法被写进主方法内部 | 补齐方法右大括号 |
| 字符串用 `== ""` | `==` 不是比较字符串内容 | 使用 `.isEmpty()` / `.equals("")` |
| Wrong Answer：返回较短的 `"AB"` 而不是 `"ABAB"` | `checkrepeat()` 从短到长寻找，找到了最小重复单位，而题目要求最长公共因子 | 从最长候选开始向下检查 |
| 最长公共前缀失败后直接返回空 | 更短前缀可能仍是正确答案 | 每轮删除最后一个字符并重新检查两个原字符串 |

### 可以改进

#### 删除未使用变量

```java
int k = candidate.length();
```

在主方法中没有被使用，可以删除。

#### 用 `while` 表达候选不断缩短更清楚

当前：

```java
for (int i = candidate.length(); i > 0; i--)
```

变量 `i` 没有真正参与候选计算，只是控制循环次数。可以写成：

```java
while (!candidate.isEmpty()) {
    if (checkcandidate(str1, candidate)
            && checkcandidate(str2, candidate)) {
        return candidate;
    }

    candidate = candidate.substring(
        0,
        candidate.length() - 1
    );
}
```

#### `checkcandidate()` 可以发现失败后立刻返回

当前版本统计全部相同块。更简洁的写法：

```java
private boolean checkCandidate(String str, String candidate) {
    if (candidate.isEmpty()
            || str.length() % candidate.length() != 0) {
        return false;
    }

    for (int start = 0;
         start < str.length();
         start += candidate.length()) {

        String piece = str.substring(
            start,
            start + candidate.length()
        );

        if (!piece.equals(candidate)) {
            return false;
        }
    }

    return true;
}
```

这样不需要 `counter` 和 `k`。

## 8. 复杂度

设两个字符串总长度约为 `n`，最长公共前缀长度为 `m`。

- 最多尝试 `m` 个候选；
- 每个候选最多扫描两个原字符串；
- **最坏时间复杂度：** 约 `O(m × n)`，长度相近时可视为 `O(n²)`；
- **额外空间：** 公共前缀和临时子字符串约 `O(n)`。

题目字符串长度上限较小，因此该版本能够通过。后续复刷时可以学习 `字符串拼接一致性 + 长度最大公约数` 的 `O(n)` 参考方案，但今天不要求重写。
