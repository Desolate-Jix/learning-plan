## 任务 1｜Easy 热身

[1071. Greatest Common Divisor of Strings](https://leetcode.com/problems/greatest-common-divisor-of-strings/)

- **中文：** 字符串的最大公因子
- **白名单位置：** Array / String 第 2 题
- **预计时间：** 25～35 分钟

### 先理解题目

如果一个字符串可以重复若干次组成另一个字符串，那么它就是另一个字符串的“因子”。

例如：

```text
"ABC" 重复 2 次 = "ABCABC"
```

所以：

```text
str1 = "ABCABC"
str2 = "ABC"
答案 = "ABC"
```

另一个例子：

```text
str1 = "ABABAB"
str2 = "ABAB"
答案 = "AB"
```

今天要思考：

1. 两个字符串是否由同一个最小重复单位组成；
2. 候选字符串长度为什么必须同时整除两个字符串长度；
3. 如果没有共同重复单位，为什么返回空字符串 `""`。

### 今天可能用到的 Java

```java
str.length()
str.substring(start, end)
str1.equals(str2)
length % candidateLength
```

特别注意：比较字符串内容使用：

```java
str1.equals(str2)
```

不要使用：

```java
str1 == str2
```

## 任务 2｜Medium 主任务

[238. Product of Array Except Self](https://leetcode.com/problems/product-of-array-except-self/)

- **中文：** 除自身以外数组的乘积
- **白名单位置：** Array / String 第 7 题
- **预计时间：** 60～80 分钟

### 题目目标

例如：

```text
nums = [1, 2, 3, 4]
```

输出：

```text
[24, 12, 8, 6]
```

因为：

```text
下标 0：2 × 3 × 4 = 24
下标 1：1 × 3 × 4 = 12
下标 2：1 × 2 × 4 = 8
下标 3：1 × 2 × 3 = 6
```

### 今天要理解的核心

对每个下标 `i`：

```text
answer[i] = i 左边所有数的乘积 × i 右边所有数的乘积
```

它和 Pivot Index 的思想相似：

```text
整体被拆成：左边 + 当前 + 右边
```

这题把加法换成乘法：

```text
结果 = 左边乘积 × 右边乘积
```

题目不允许使用除法，因此不能先算总乘积再除以 `nums[i]`。

### 建议思考顺序

1. 先尝试暴力：对每个 `i` 重新乘其他元素，理解为什么是 `O(n²)`；
2. 再想能否提前保存每个位置左边的乘积；
3. 从右向左维护一个 `rightProduct`；
4. 把左边结果与右边乘积相乘。

今天先理解，不要求一开始就写出最省空间版本。

### 今天可能用到的 Java

```java
int[] answer = new int[nums.length];
nums.length
answer[i] = value;
```

乘积的初始值通常是：

```java
1
```

因为 `1` 是乘法单位元：

```text
1 × x = x
```
