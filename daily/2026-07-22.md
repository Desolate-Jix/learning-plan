## 2. 自己最终 Accepted 的代码

```java
class Solution {
    public String gcdOfStrings(String str1, String str2) {
        StringBuilder sb = new StringBuilder();
        int n1 = str1.length();
        int n2 = str2.length();

        for (int i = 0; i < n1 && i < n2; i++) {
            if (str1.charAt(i) == str2.charAt(i)) {
                sb.append(str1.charAt(i));
            } else {
                break;
            }
        }

        String candidate = sb.toString();

        for (int i = candidate.length(); i > 0; i--) {
            if (checkcandidate(str1, candidate)
                    && checkcandidate(str2, candidate)) {
                return candidate;
            } else {
                candidate = candidate.substring(
                    0,
                    candidate.length() - 1
                );
            }
        }

        return "";
    }

    public boolean checkcandidate(String str, String candidate) {
        int n1 = str.length();
        int n2 = candidate.length();

        if (candidate.length() == 0) {
            return false;
        } else {
            if (n1 % n2 == 0) {
                int k = n1 / n2;
                int counter = 0;

                for (int i = 0; i < n1; i = i + n2) {
                    if (str.substring(i, i + n2).equals(candidate)) {
                        counter++;
                    }
                }

                if (counter == k) {
                    return true;
                } else {
                    return false;
                }
            } else {
                return false;
            }
        }
    }
}
```

> 上面只整理了缩进，并删除了主方法中没有使用的 `int k`；算法结构与实际 Accepted 版本一致。

## 3. 自己完成的算法思路

### 第一步：找两个字符串的最长公共前缀

例如：

```text
str1 = "ABABAB"
str2 = "ABAB"
```

逐字符比较后得到：

```text
candidate = "ABAB"
```

答案一定是两个字符串共同拥有的前缀，因此不必从字符串中间寻找候选。

### 第二步：从最长候选开始逐渐删除最后一个字符

检查顺序：

```text
"ABAB"
"ABA"
"AB"
"A"
```

每次都回到两个原字符串，检查当前候选能不能重复铺满它们：

```java
checkcandidate(str1, candidate)
checkcandidate(str2, candidate)
```

第一个同时成功的候选就是最长答案。

### 第三步：检查候选能否重复组成目标字符串

例如：

```text
target = "ABABAB"
candidate = "AB"
```

先检查长度：

```text
6 % 2 == 0
```

然后按候选长度切块：

```text
"AB" | "AB" | "AB"
```

每一块都和候选 `.equals()`，所以返回 `true`。

## 5. 今日字符串操作

### 字符串长度

```java
str.length()
```

数组长度是 `array.length`，字符串长度是 `str.length()`。

### 读取单个字符

```java
str.charAt(i)
```

`charAt()` 返回 `char`，字符比较使用：

```java
str1.charAt(i) == str2.charAt(i)
```

不能对 `char` 调用 `.equals()`。

### 截取字符串

```java
str.substring(start, end)
```

范围是 `[start, end)`，不包含 `end`。

删除最后一个字符：

```java
str = str.substring(0, str.length() - 1);
```

### 比较字符串内容

```java
piece.equals(candidate)
```

不要使用：

```java
piece == candidate
```

### 判断空字符串

```java
str.isEmpty()
```

或者：

```java
str.length() == 0
```

## 6. 今日出现的错误与原因

| 问题 | 根因 | 修正 |
|---|---|---|
| `char cannot be dereferenced` | `charAt()` 返回基本类型 `char`，不能调用 `.equals()` | 字符使用 `==` 比较 |
| `StringIndexOutOfBoundsException` | 循环误写为 `1 < n2`，访问了较短字符串不存在的下标 | 改为 `i < n1 && i < n2` |
| `/ by zero` | 公共前缀为空，`candidate.length() == 0`，随后执行取余 | 先处理空候选，或让候选循环自然跳过 |
| `illegal start of expression` | `gcdOfStrings()` 少一个 `}`，辅助方法被写进主方法内部 | 补齐方法右大括号 |
| 字符串使用 `== ""` | `==` 不负责比较字符串内容 | 使用 `.isEmpty()` 或 `.equals("")` |
| 返回较短的 `"AB"` 而不是 `"ABAB"` | `checkrepeat()` 从短到长寻找，找到最小重复单位 | 题目要最长公共因子，应从最长候选向下检查 |
| 最长公共前缀失败后直接返回空 | 更短前缀仍可能是正确答案 | 每轮删除最后一个字符并重新检查两个原字符串 |

## 7. 当前版本的可读性改进

### 使用 `while` 表达候选不断缩短

当前 `for` 的变量没有参与计算，更清楚的写法是：

```java
while (!candidate.isEmpty()) {
    if (checkcandidate(str1, candidate)
            && checkcandidate(str2, candidate)) {
        return candidate;
    }

    candidate = candidate.substring(
        0,
        candidate.length() - 1
    );
}

return "";
```

### 验证方法遇到失败立即返回

```java
private boolean checkCandidate(String str, String candidate) {
    if (candidate.isEmpty()
            || str.length() % candidate.length() != 0) {
        return false;
    }

    for (int start = 0;
         start < str.length();
         start += candidate.length()) {

        String piece = str.substring(
            start,
            start + candidate.length()
        );

        if (!piece.equals(candidate)) {
            return false;
        }
    }

    return true;
}
```

这样不需要 `counter` 和 `k`。

## 8. 自己版本的复杂度

设两个字符串总长度约为 `n`，最长公共前缀长度为 `m`：

- 最多尝试 `m` 个候选；
- 每个候选最多扫描两个原字符串；
- **最坏时间复杂度：** 约 `O(m × n)`，长度相近时可视为 `O(n²)`；
- **额外空间：** 公共前缀和临时子字符串约 `O(n)`。

题目字符串长度上限较小，因此该版本能够通过。

## 9. 数学快捷解法：拼接一致性 + 长度最大公约数

这道题还有一个更短、更适合复刷和面试的 `O(n)` 思路。

### 第一步：判断两个字符串是否来自同一个重复单位

比较：

```java
(str1 + str2).equals(str2 + str1)
```

如果两个字符串都由同一个基础字符串重复组成，那么交换拼接顺序后结果仍然相同。

例如：

```text
str1 = "ABABAB" = "AB" × 3
str2 = "ABAB"   = "AB" × 2
```

所以：

```text
str1 + str2 = "ABABABABAB"
str2 + str1 = "ABABABABAB"
```

结果相同，说明存在共同重复单位。

反例：

```text
str1 = "LEET"
str2 = "CODE"

str1 + str2 = "LEETCODE"
str2 + str1 = "CODELEET"
```

结果不同，因此直接返回空字符串。

### 第二步：求两个字符串长度的最大公约数

如果共同重复单位存在，那么最长公共字符串因子的长度就是：

```text
gcd(str1.length(), str2.length())
```

例如：

```text
str1.length() = 6
str2.length() = 4

gcd(6, 4) = 2
```

答案就是：

```java
str1.substring(0, 2)
```

也就是：

```text
"AB"
```

### 欧几里得算法求最大公约数

```java
private int gcd(int a, int b) {
    while (b != 0) {
        int remainder = a % b;
        a = b;
        b = remainder;
    }

    return a;
}
```

以 `gcd(6, 4)` 为例：

```text
6 % 4 = 2  → a = 4，b = 2
4 % 2 = 0  → a = 2，b = 0
```

当 `b == 0` 时，`a` 就是最大公约数，因此返回 `2`。

### 数学快捷解法完整代码

```java
class Solution {
    public String gcdOfStrings(String str1, String str2) {
        if (!(str1 + str2).equals(str2 + str1)) {
            return "";
        }

        int gcdLength = gcd(str1.length(), str2.length());
        return str1.substring(0, gcdLength);
    }

    private int gcd(int a, int b) {
        while (b != 0) {
            int remainder = a % b;
            a = b;
            b = remainder;
        }

        return a;
    }
}
```

### 三个关键例子

```text
"ABABAB" 与 "ABAB"
长度 6 和 4，gcd = 2，返回 "AB"
```

```text
"AAAAAA" 与 "AAAA"
长度 6 和 4，gcd = 2，返回 "AA"
```

```text
"ABABABAB" 与 "ABAB"
长度 8 和 4，gcd = 4，返回 "ABAB"
```

最后一个例子说明：题目寻找的不是最小重复单位，而是**最长公共字符串因子**。

### 数学版本复杂度

设两个字符串长度分别为 `n` 和 `m`：

- 两次拼接及比较需要 `O(n + m)` 时间；
- 欧几里得算法需要 `O(log(min(n, m)))` 时间；
- 总时间复杂度由字符串比较主导，为 **`O(n + m)`**；
- Java 中拼接会创建新字符串，因此额外空间约为 **`O(n + m)`**。

### 两种方案对比

| 方案 | 核心过程 | 时间复杂度 | 特点 |
|---|---|---:|---|
| 自己完成的验证法 | 找公共前缀，逐渐缩短，每次回原字符串验证 | 最坏约 `O(n²)` | 直观，能从题意推导 |
| 数学快捷法 | 拼接一致性判断，再取长度最大公约数 | `O(n + m)` | 代码短，适合复刷和面试 |

数学版本不是用来否定自己的方案。自己的方案帮助理解“最长候选如何验证”；数学版本是在理解题意后进一步压缩搜索过程。
