## 1. 双指针是什么

```java
int left = 0;
int right = chars.length - 1;
```

`left`、`right` 都只是记录当前位置的整数变量：

```text
      left               right
        ↓                   ↓
下标：  0   1   2   3   4
字符：  h   e   l   l   o
```

- 左边不是元音：`left++`
- 右边不是元音：`right--`
- 两边都是元音：交换
- `left >= right`：结束

奇数个元音不需要特殊处理，中间那个元音反转后仍在中间。

## 2. 今日 Java 知识

### String 转字符数组

```java
char[] chars = s.toCharArray();
```

这不是空数组，而是包含字符串全部字符的新数组。`String` 不能直接修改某个位置，`char[]` 可以。

### 字符数组转回 String

```java
return new String(chars);
```

### 交换两个字符

```java
char temp = chars[left];
chars[left] = chars[right];
chars[right] = temp;
```

### char 与 String

```java
char c = 'a';
String text = "abc";
```

- `char`：一个字符，单引号
- `String`：一串字符，双引号

### indexOf

```java
String vowels = "aeiouAEIOU";
```

- 找到字符：返回第一次出现的下标
- 找不到：返回 `-1`

因此：

```java
return vowels.indexOf(c) != -1;
```

表示“`c` 是元音”。

## 3. 出现过的错误

| 写法 / 问题 | 原因 | 修正 |
|---|---|---|
| `s.tocharArray()` | 方法名区分大小写 | `s.toCharArray()` |
| 辅助方法访问主方法里的 `vowels` | 局部变量只在声明它的方法中可见 | 在辅助方法内声明或作为参数传入 |
| 右指针写成 `r++` | 右指针应向左移动 | `r--` |
| 外层写 `while (l != r)` | 指针可能直接交叉，仍然不相等 | `while (l < r)` |
| `whetherVowels(c) != true` | 合法但较绕 | `!whetherVowels(c)` |

### 变量作用域

下面的 `vowels` 只能在 `reverseVowels` 方法内部使用：

```java
public String reverseVowels(String s) {
    String vowels = "aeiouAEIOU";
}
```

另一个方法不能直接访问它，所以当天把 `vowels` 放进了辅助方法。

## 4. Runtime Error：Index -1

报错说明右指针已经减到 `-1`，代码仍访问 `chars[right]`。

根因是初版使用：

```java
while (left != right)
```

指针可能从：

```text
left = 3, right = 4
```

直接变成：

```text
left = 4, right = 3
```

此时仍然“不相等”，循环错误地继续。左右双指针应使用：

```java
while (left < right)
```

## 5. 自己最终 Accepted 的代码

```java
class Solution {
    public String reverseVowels(String s) {
        int l = 0;
        int r = s.length() - 1;
        char[] ch = s.toCharArray();

        while (l < r) {
            if (whetherVowels(ch[l]) != true) {
                l++;
            }

            if (whetherVowels(ch[r]) != true) {
                r--;
            }

            if (whetherVowels(ch[l]) && whetherVowels(ch[r])) {
                char tem = ch[l];
                ch[l] = ch[r];
                ch[r] = tem;
                l++;
                r--;
            }
        }

        return new String(ch);
    }

    public boolean whetherVowels(char a) {
        String vowels = "aeiouAEIOU";
        if (vowels.indexOf(a) == -1) {
            return false;
        } else {
            return true;
        }
    }
}
```

## 6. 重要观察：内部用 if 也可以

用户指出：

> 用 `if` 也可以，就是每次只走一步。

这是正确的。

当前版本中，内部 `if` 每次外层循环最多让一个指针移动一步，但外层 `while (l < r)` 会继续执行，所以最终仍会跳过所有非元音。

参考写法通常使用内部 `while`：

```java
while (left < right && !isVowel(chars[left])) {
    left++;
}
```

它会在一次外层循环中连续跳过多个非元音。

| 写法 | 行为 | 复杂度 |
|---|---|---|
| 内部 `if` | 每轮最多移动一步 | `O(n)` |
| 内部 `while` | 一轮连续跳过多个位置 | `O(n)` |

两种写法都正确。因为每个指针都只单向移动，最多各走完整个字符串一次，所以总时间复杂度相同。

## 8. 推荐简化版

```java
class Solution {
    public String reverseVowels(String s) {
        char[] chars = s.toCharArray();
        int left = 0;
        int right = chars.length - 1;

        while (left < right) {
            while (left < right && !isVowel(chars[left])) {
                left++;
            }
            while (left < right && !isVowel(chars[right])) {
                right--;
            }

            if (left < right) {
                char temp = chars[left];
                chars[left] = chars[right];
                chars[right] = temp;
                left++;
                right--;
            }
        }

        return new String(chars);
    }

    private boolean isVowel(char c) {
        return "aeiouAEIOU".indexOf(c) != -1;
    }
}
```
