## 今天要理解的算法模型

准备两个下标：

```text
left：从字符串最左边开始
right：从字符串最右边开始
```

基本思考：

1. `left` 不是元音时，向右移动；
2. `right` 不是元音时，向左移动；
3. 两边都指向元音时，交换两个字符；
4. 交换后，两个指针都继续向中间移动；
5. 当 `left >= right` 时结束。

## 今日 Java 新知识

### 1. String 转成可修改的字符数组

```java
char[] chars = s.toCharArray();
```

原因：`String` 不能直接修改某个位置，但 `char[]` 可以。

### 2. 读取和修改字符数组

```java
char current = chars[left];
chars[left] = 'a';
```

字符数组使用：

```java
chars[index]
chars.length
```

### 3. 交换两个位置

```java
char temp = chars[left];
chars[left] = chars[right];
chars[right] = temp;
```

### 4. 字符数组重新转成 String

```java
return new String(chars);
```

### 编译错误 1：方法名大小写

当时写成：

```java
s.tocharArray()
```

Java 方法名区分大小写，正确写法是：

```java
s.toCharArray()
```

### 编译错误 2：局部变量作用域

当时在 `reverseVowels` 方法内部声明：

```java
String vowels = "aeiouAEIOU";
```

但辅助方法：

```java
public boolean whetherVowels(char a)
```

是另一个独立方法，不能直接读取 `reverseVowels` 内部的局部变量 `vowels`，因此出现 `cannot find symbol`。

可选修正方式：

1. 在辅助方法内部重新声明元音字符串；
2. 把 `vowels` 作为参数传入；
3. 把它声明为类级别字段。

当前最容易理解的写法是：

```java
public boolean whetherVowels(char a) {
    String vowels = "aeiouAEIOU";
    return vowels.indexOf(a) != -1;
}
```

### 第一版还需要修复的逻辑问题

#### 右指针方向写反

右指针应该从右向左移动：

```java
r--;
```

不能写：

```java
r++;
```

否则会向数组外侧移动并最终越界。

#### 找非元音时不能只移动一次

当前使用单个 `if`：

```java
if (!whetherVowels(ch[l])) {
    l++;
}
```

如果连续出现多个辅音，只移动一次后就可能直接进入交换判断。更适合使用内部 `while`，让指针一直走到元音或与另一指针相遇：

```java
while (l < r && !whetherVowels(ch[l])) {
    l++;
}

while (l < r && !whetherVowels(ch[r])) {
    r--;
}
```

之后两边才都指向元音，再交换。

#### 布尔判断不必写 `!= true`

下面写法合法但不够自然：

```java
whetherVowels(ch[l]) != true
```

更直接的是：

```java
!whetherVowels(ch[l])
```

意思是“不是元音”。
