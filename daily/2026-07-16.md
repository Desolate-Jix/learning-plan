## 今天要理解的算法模型

准备两个下标：

```text
left：从字符串最左边开始
right：从字符串最右边开始
```

基本思考：

1. `left` 不是元音时，向右移动；
2. `right` 不是元音时，向左移动；
3. 两边都指向元音时，交换两个字符；
4. 交换后，两个指针都继续向中间移动；
5. 当 `left >= right` 时结束。

## 今日 Java 新知识

### 1. String 转成可修改的字符数组

```java
char[] chars = s.toCharArray();
```

原因：`String` 不能直接修改某个位置，但 `char[]` 可以。

### 2. 读取和修改字符数组

```java
char current = chars[left];
chars[left] = 'a';
```

字符数组使用：

```java
chars[index]
chars.length
```

### 3. 交换两个位置

```java
char temp = chars[left];
chars[left] = chars[right];
chars[right] = temp;
```

### 4. 字符数组重新转成 String

```java
return new String(chars);
```

### 5. 判断元音时允许查询

可以使用自己能理解的任意一种方式：

- 多个 `==` 和 `||`；
- 一个保存了大小写元音的字符串，再使用 `indexOf()`；
- 自己写一个 `isVowel(char c)` 方法。
