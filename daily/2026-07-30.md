### 为什么记为 B

这是第一次正式使用 `HashMap`。解题方向在理解题意后能够接受，但实现过程中查看了以下提示：

```text
Map<Integer, Integer>
put()
getOrDefault()
values()
Set.add() 的 boolean 返回值
```

因此不记为完全独立完成。后续需要闭卷重写一次，能够自己选择 `HashMap + HashSet` 并写出 API 后，再提升掌握等级。

## 最终 Accepted 代码

```java
class Solution {
    public boolean uniqueOccurrences(int[] arr) {
        Map<Integer, Integer> map = new HashMap<>();

        for (int number : arr) {
            map.put(number, map.getOrDefault(number, 0) + 1);
        }

        Set<Integer> set = new HashSet<>();

        for (int count : map.values()) {
            if (!set.add(count)) {
                return false;
            }
        }

        return true;
    }
}
```

## 核心数据流

```text
原数组
→ HashMap：数字 → 出现次数
→ 遍历 map.values()
→ HashSet：保存已经出现过的次数
→ add() 返回 false 时，说明次数重复
```

例如：

```text
arr = [1,2,2,1,1,3]

Map：
1 → 3
2 → 2
3 → 1

Set 依次加入：
3 → true
2 → true
1 → true

最终返回 true
```

拆开：

```java
int oldCount = map.getOrDefault(number, 0);

map.put(number, newCount);
```

## HashMap 与 HashSet 的职责区别

```text
HashMap：保存 key → value
本题中：数字 → 出现次数

HashSet：只保存不重复的值
本题中：已经出现过的次数
```

## 调试记录

1. `Integer` 最初误写为 `Interger`；
2. `getOrDefault()` 需要两个参数：key 和默认值；
3. 遍历所有 value 使用 `values()`，不是 `value()`；
4. 原本考虑只用 Set 重复扫描数组，逻辑可行但时间复杂度为 `O(n²)`；
5. `HashMap + HashSet` 将平均时间复杂度优化为 `O(n)`。
