# 任务 A｜1207. Unique Number of Occurrences

[打开题目](https://leetcode.com/problems/unique-number-of-occurrences/)

- **中文：** 独一无二的出现次数
- **难度：** Easy
- **主题：** `HashMap` 统计频率 + `HashSet` 检查频率是否重复
- **目标平均复杂度：** `O(n)` 时间、`O(n)` 空间

## 题目目标

先统计每个数字出现多少次，再判断这些“出现次数”是否全部不同。

例子：

```text
arr = [1,2,2,1,1,3]

1 → 3 次
2 → 2 次
3 → 1 次

次数 3、2、1 都不同，所以返回 true。
```

反例：

```text
arr = [1,2]

1 → 1 次
2 → 1 次

出现次数重复，所以返回 false。
```

## 今天的新语法：HashMap

创建：

```java
Map<Integer, Integer> counts = new HashMap<>();
```

两个 `Integer` 分别表示：

```text
第一个：key，数组中的数字
第二个：value，该数字出现的次数
```

更新次数：

```java
counts.put(number, counts.getOrDefault(number, 0) + 1);
```

拆开理解：

```text
getOrDefault(number, 0)
→ number 已存在：取旧次数
→ number 不存在：返回默认值 0

然后 +1，再用 put() 写回 Map。
```

遍历所有次数：

```java
for (int count : counts.values()) {
}
```

用 `HashSet` 检查重复：

```java
Set<Integer> seenCounts = new HashSet<>();
```

`add()` 会返回布尔值：

```text
第一次加入某个次数 → true
重复加入同一个次数 → false
```

# 任务 B｜1493. Longest Subarray of 1's After Deleting One Element

[打开题目](https://leetcode.com/problems/longest-subarray-of-1s-after-deleting-one-element/)

- **中文：** 删掉一个元素以后全为 1 的最长子数组
- **难度：** Medium
- **主题：** 可变长度滑动窗口
- **目标复杂度：** `O(n)` 时间、`O(1)` 额外空间

## 与 1004 的关系

1004：

```text
窗口里最多允许 k 个 0
答案是合法窗口长度
```

1493：

```text
必须删除一个元素
可以把问题看成：窗口里最多允许 1 个 0
最后必须从窗口长度中减去 1
```

因此：

```text
合法条件：zeroCount <= 1
答案候选：right - left
```

为什么不是 `right - left + 1`：

```text
窗口原长度 = right - left + 1
必须删除一个元素
删除后长度 = right - left
```

即使整个数组都是 `1`，也必须删掉一个，所以答案是 `n - 1`，这正是减一的原因。

## 手算例子

```text
nums = [1,1,0,1]
```

窗口可以包含一个 `0`：

```text
[1,1,0,1] 长度 4
删除其中的 0
得到 3 个连续 1
```

答案：

```text
4 - 1 = 3
```
