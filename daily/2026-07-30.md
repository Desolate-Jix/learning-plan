### 为什么记为 B

这是第一次正式使用 `HashMap`。实现过程中查看了以下提示：

```text
Map<Integer, Integer>
put()
getOrDefault()
values()
Set.add() 的 boolean 返回值
```

因此不记为完全独立完成。后续闭卷重写一次，能够自己选择 `HashMap + HashSet` 并写出 API 后，再提升掌握等级。

## 最终 Accepted 代码

```java
class Solution {
    public boolean uniqueOccurrences(int[] arr) {
        Map<Integer, Integer> map = new HashMap<>();

        for (int number : arr) {
            map.put(number, map.getOrDefault(number, 0) + 1);
        }

        Set<Integer> set = new HashSet<>();

        for (int count : map.values()) {
            if (!set.add(count)) {
                return false;
            }
        }

        return true;
    }
}
```

## 核心数据流

```text
原数组
→ HashMap：数字 → 出现次数
→ 遍历 map.values()
→ HashSet：保存已经出现过的次数
→ add() 返回 false 时，说明次数重复
```

## 今天掌握的 HashMap API

统计次数的标准写法：

```java
map.put(number, map.getOrDefault(number, 0) + 1);
```

## HashMap 与 HashSet 的职责区别

```text
HashMap：保存 key → value
本题中：数字 → 出现次数

HashSet：只保存不重复的值
本题中：已经出现过的次数
```

## 调试记录

1. `Integer` 最初误写为 `Interger`；
2. `getOrDefault()` 需要 key 和默认值两个参数；
3. 遍历所有 value 使用 `values()`，不是 `value()`；
4. 只用 Set 重复扫描数组也能实现，但时间复杂度为 `O(n²)`；
5. `HashMap + HashSet` 将平均时间复杂度优化为 `O(n)`。

# 任务 B｜1493. Longest Subarray of 1's After Deleting One Element

- **主题：** 可变长度滑动窗口
- **时间复杂度：** `O(n)`
- **额外空间：** `O(1)`
- **掌握等级：** B+

## 最终 Accepted 代码

```java
class Solution {
    public int longestSubarray(int[] nums) {
        int zero = 0;
        int i = 0;
        int j = 0;
        int n = nums.length;
        int max = 0;

        for (; j < n; j++) {
            if (nums[j] == 0) {
                zero++;
            }

            while (zero > 1) {
                if (nums[i] == 0) {
                    zero--;
                }
                i++;
            }

            if (max < j - i) {
                max = j - i;
            }
        }

        return max;
    }
}
```

## 核心思路

```text
窗口中最多允许一个 0
右边界 j 不断扩张
zero > 1 时移动左边界 i，直到窗口重新合法
窗口原长度为 j - i + 1
题目要求必须删除一个元素
所以候选答案为 j - i
```

## 调试记录

第一次把候选长度写成：

```java
i - j
```

因为 `i <= j`，结果通常小于等于 0，`max` 无法正确更新。修正为：

```java
j - i
```

这一错误属于下标相减方向错误，不是滑动窗口结构错误。
