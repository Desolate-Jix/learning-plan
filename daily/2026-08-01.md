# 一、数据库基础复习

## 1. 关系型数据库

关系型数据库把数据放在一张张表中：

```text
一行：一条记录，row / tuple
一列：一个字段，column / attribute
一张表：一种实体或一种关系
```

常见关系型数据库：MySQL、PostgreSQL、SQL Server。

## 2. 主键和外键

### 主键 Primary Key

主键唯一标识一行数据：

```text
唯一
不能为 NULL
可以由一个字段或多个字段组成
```

多个字段共同组成的主键称为复合主键。

### 外键 Foreign Key

外键引用另一张表的主键，用于连接数据并保证引用完整性。

```text
User 1 —— N Order
```

一对多关系中，外键通常放在“多”的一方：

```text
Order.user_id → User.user_id
```

### 多对多关系

多对多通常使用中间表：

```text
Student N —— N Course

Enrollment(
    student_id FK,
    course_id FK
)
```

# 二、范式：从一张混合表拆到 3NF

范式的目标不是机械拆表，而是：

> 把不同事实放进各自负责的表里，减少重复数据和修改错误。

以学生选课为例：

```text
Enrollment
---------------------------------------------------------
student_id
student_name
course_id
course_name
teacher_id
teacher_name
grade
```

候选复合主键：

```text
(student_id, course_id)
```

因为一个学生可以选多门课，一门课也可以被多个学生选择。

## 1NF：一个格子一个值

不推荐：

```text
student_id | courses
1001       | Java, 数据库, 网络
```

这里一个格子保存了多个课程。

满足 1NF：

```text
1001 | Java
1001 | 数据库
1001 | 网络
```

记忆：

> 每个单元格只保存一个原子值。

## 2NF：依赖完整复合主键

当前主键：

```text
(student_id, course_id)
```

依赖关系：

```text
student_id → student_name
course_id → course_name
course_id → teacher_id
course_id → teacher_name
(student_id, course_id) → grade
```

问题：

```text
student_name 只依赖 student_id
course_name 只依赖 course_id
```

它们只依赖复合主键的一部分，称为部分依赖。

拆分：

```text
Student(
    student_id PK,
    student_name
)

Course(
    course_id PK,
    course_name,
    teacher_id,
    teacher_name
)

Enrollment(
    student_id PK, FK,
    course_id  PK, FK,
    grade
)
```

`grade` 必须知道“哪个学生 + 哪门课”才能确定，因此依赖完整复合主键。

记忆：

> 有复合主键时，普通字段不能只依赖主键的一部分。

如果主键只有一个字段，一般不会出现部分依赖，因此满足 1NF 后通常也满足 2NF。

## 3NF：普通字段不能依赖另一个普通字段

当前 Course：

```text
Course(
    course_id PK,
    course_name,
    teacher_id,
    teacher_name
)
```

依赖关系：

```text
course_id → teacher_id
teacher_id → teacher_name
```

所以出现了：

```text
course_id → teacher_id → teacher_name
```

`teacher_name` 通过另一个普通字段 `teacher_id` 间接依赖主键，这叫传递依赖。

继续拆分：

```text
Teacher(
    teacher_id PK,
    teacher_name
)

Course(
    course_id PK,
    course_name,
    teacher_id FK
)
```

最终结构：

```text
Student：保存学生事实
Teacher：保存老师事实
Course：保存课程事实及授课老师
Enrollment：保存学生选课及成绩
```

### 范式快速检查

```text
1NF：一个格子是否放了多个值？
2NF：复合主键存在时，字段是否只依赖主键的一部分？
3NF：普通字段是否依赖另一个普通字段？
```

口诀：

```text
1NF：一个格子一个值
2NF：依赖完整主键
3NF：只依赖主键，不依赖普通字段
```

# 三、Python 基础

## 1. 变量和类型

Python 不要求在变量前声明类型：

```python
age = 24              # int
height = 1.67         # float
name = "Jix"          # str
is_student = True     # bool
```

Python 是动态类型语言：

```python
value = 10
value = "hello"
```

可以检查类型：

```python
print(type(value))

if isinstance(value, int):
    print("value is an integer")
```

## 2. True、False 和 None

```python
is_student = True
has_membership = False
result = None
```

判断空值推荐：

```python
if result is None:
    print("No result")

if result is not None:
    print(result)
```

## 3. 输出和 f-string

```python
name = "Jix"
age = 24

print(f"Hello, {name}. You are {age}.")
```

## 4. input()

`input()` 让程序等待键盘输入，返回值永远是字符串：

```python
name = input("Enter your name: ")
age_text = input("Enter your age: ")
```

数字输入需要转换：

```python
age = int(input("Enter your age: "))
height = float(input("Enter your height: "))
```

不能直接用 `bool(input())` 解析 yes / no：

```python
bool("no")  # True，因为非空字符串是真值
```

正确方式：

```python
answer = input("Are you a student? yes/no: ").strip().lower()
is_student = answer == "yes"
```

## 5. 字符串常用方法

```python
text = "  Hello Python  "

text.strip()       # 去除两端空格
text.lower()       # 转小写
text.upper()       # 转大写
text.startswith("H")
text.endswith("n")
"Python" in text
len(text)
```

## 6. 条件判断

```python
age = 24
is_student = True

if age < 18:
    price = 15
elif is_student:
    price = 20
else:
    price = 30

print(f"Your membership price is ${price}.")
```

Python 使用冒号和缩进表示代码块，不使用花括号。

## 7. 比较和逻辑运算

```python
age == 18
age != 18
age >= 18

age >= 18 and is_student
age < 18 or age >= 65
not is_student
```

Python 支持连续比较：

```python
if 18 <= age < 65:
    print("Adult")
```

# 四、C# 基础

## 1. 类型

```csharp
int age = 24;
double height = 1.67;
string name = "Jix";
bool isStudent = true;
```

与 Java 的主要名称区别：

```text
Java String    → C# string
Java boolean   → C# bool
```

C# 可以使用 `var` 让编译器推断类型：

```csharp
var age = 24;         // 推断为 int
var name = "Jix";     // 推断为 string
```

`var` 仍然是静态类型，不等于 Python 的动态类型。

## 2. 输出

```csharp
Console.WriteLine("Hello");
Console.Write("Hello");
```

## 3. 字符串插值

```csharp
string name = "Jix";
int age = 24;

Console.WriteLine($"Hello, {name}. You are {age}.");
```

C# 字符串插值在引号前使用 `$`。

## 4. 输入

```csharp
Console.Write("Enter your name: ");
string name = Console.ReadLine();
```

`Console.ReadLine()` 返回字符串。

## 5. 类型转换

```csharp
int age = int.Parse(Console.ReadLine());
double price = double.Parse("19.9");
string text = 123.ToString();
```

更安全的整数转换：

```csharp
string input = Console.ReadLine();
bool success = int.TryParse(input, out int age);

if (success)
{
    Console.WriteLine($"Your age is {age}.");
}
else
{
    Console.WriteLine("Invalid age.");
}
```

## 6. 条件判断

```csharp
if (age < 18)
{
    price = 15;
}
else if (isStudent)
{
    price = 20;
}
else
{
    price = 30;
}
```

C# 和 Java 都使用圆括号、花括号与分号。

## 7. 逻辑运算符

```csharp
&&  // and
||  // or
!   // not
```
