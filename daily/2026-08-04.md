## 最终 Accepted 代码

```java
class Solution {
    public int maxOperations(int[] nums, int k) {
        Map<Integer, Integer> map = new HashMap<>();
        int counter = 0;

        for (int num : nums) {
            int need = k - num;

            if (map.getOrDefault(need, 0) > 0) {
                map.put(need, map.get(need) - 1);
                counter++;
            } else {
                map.put(num, map.getOrDefault(num, 0) + 1);
            }
        }

        return counter;
    }
}
```

## 核心状态

```text
Map 的 key：数字
Map 的 value：该数字还有几个尚未配对

当前数字 num
需要的补数 need = k - num

need 的剩余数量 > 0：
    使用一个 need，数量减一，完成一组
否则：
    保存当前 num，等待后面的数字与它配对
```

## 重复数字为什么不会出错

例如：

```text
nums = [1,1,4,4]
k = 5
```

Map 会先记录两个尚未使用的 `1`：

```text
{1=2}
```

每遇到一个 `4`，就使用一个 `1`：

```text
第一个 4 → {1=1}，counter=1
第二个 4 → {1=0}，counter=2
```

value 是数量，因此同一个元素不会被重复使用。

## ArrayList 版本为什么超时

原方案中的操作：

```java
list.remove(0);
list.remove(Integer.valueOf(target));
```

都可能需要查找或移动后续元素，单次最坏为 `O(n)`。循环执行约 `n` 次，总复杂度达到 `O(n²)`。

这次需要记住：

> 逻辑正确不代表复杂度足够。频繁查找、删除和计数时，应考虑 HashMap。

## Java API 复习

```java
map.containsKey(key);          // key 是否存在
map.get(key);                  // 获取 value；key 不存在时返回 null
map.getOrDefault(key, 0);      // 不存在时使用默认值 0
map.put(key, value);           // 新增或覆盖 value
map.remove(key);               // 删除整个 key
```

`ArrayList<Integer>` 的两个 `remove` 重载：

```java
int value = list.remove(index);              // 按下标删除，返回被删除的元素
boolean ok = list.remove(Integer.valueOf(x)); // 按数值删除，返回是否成功
```
