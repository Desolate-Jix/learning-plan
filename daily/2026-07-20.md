# 任务 1｜Find the Highest Altitude

## 结果

- **题目：** [1732. Find the Highest Altitude](https://leetcode.com/problems/find-the-highest-altitude/)
- **结果：** Accepted，80 / 80
- **提交页面：** 显示 0 ms；单次排名只作参考
- **掌握表现：** B+

## 自己最终 Accepted 的代码

```java
class Solution {
    public int largestAltitude(int[] gain) {
        int maxgain = 0;
        int n = gain.length;
        int current = 0;

        for (int i = 0; i < n; i++) {
            current = current + gain[i];
            if (current > maxgain) {
                maxgain = current;
            }
        }

        return maxgain;
    }
}
```

## 核心知识

- 当前状态来自“上一状态 + 当前变化”；
- 起点海拔 `0` 也必须参与最高值比较；
- 如果所有变化都是负数，最高海拔仍可能是起点 `0`；
- 时间复杂度 `O(n)`，额外空间 `O(1)`。

## 自己最终 Accepted 的代码

```java
class Solution {
    public int pivotIndex(int[] nums) {
        int n = nums.length;
        int sumleft = 0;
        int sumright = 0;
        int pointer = 0;

        for (; pointer < n; pointer++) {
            if (pointer == 0) {
                sumleft = 0;
                sumright = 0;

                for (int i = pointer + 1; i < n; i++) {
                    sumright = sumright + nums[i];
                }

                if (sumleft == sumright) {
                    return 0;
                }
            } else if (pointer == n - 1) {
                sumleft = 0;
                sumright = 0;

                for (int i = 0; i < pointer; i++) {
                    sumleft = sumleft + nums[i];
                }

                if (sumleft == sumright) {
                    return n - 1;
                }
            } else if (pointer > 0 && pointer < n - 1) {
                sumleft = 0;
                sumright = 0;

                for (int i = 0; i < pointer; i++) {
                    sumleft = sumleft + nums[i];
                }

                for (int i = pointer + 1; i < n; i++) {
                    sumright = sumright + nums[i];
                }

                if (sumleft == sumright) {
                    return pointer;
                }
            }
        }

        return -1;
    }
}
```

> 上面保留实际提交通过的思路，只统一了缩进和空格。

## 调试过程与错误记录

### 1. Java 不支持连续比较

错误写法：

```java
0 < pointer < n - 1
```

Java 会先把 `0 < pointer` 算成 `boolean`，再尝试比较 `boolean < int`，因此编译失败。

正确写法：

```java
pointer > 0 && pointer < n - 1
```

### 2. `missing return statement`

方法声明返回 `int`：

```java
public int pivotIndex(int[] nums)
```

因此所有执行路径必须返回整数。最终在方法末尾添加：

```java
return -1;
```

### 3. `pointer` 最初没有移动

一开始只有：

```java
int pointer = 0;
```

但没有循环更新它，因此程序永远只检查下标 `0`。修正为：

```java
for (; pointer < n; pointer++)
```

### 4. 每轮必须重新清零左右和

如果 `sumleft`、`sumright` 不清零，前一轮的结果会被下一轮继续累加。

正确做法是在每个新 `pointer` 开始时重置：

```java
sumleft = 0;
sumright = 0;
```

### 5. 左边求和不能包含中心元素

错误边界：

```java
for (int i = 0; i <= pointer; i++)
```

这会把 `nums[pointer]` 也算进左边。

正确边界：

```java
for (int i = 0; i < pointer; i++)
```

右边则从：

```java
pointer + 1
```

开始。

## 为什么这版比较慢

每个 `pointer` 都重新扫描左边和右边，因此总体复杂度为：

```text
O(n²)
```

虽然 747 / 747 全部通过，但提交耗时 317 ms，说明存在大量重复计算。

## 推荐的累计和优化版

```java
class Solution {
    public int pivotIndex(int[] nums) {
        int totalSum = 0;

        for (int num : nums) {
            totalSum += num;
        }

        int leftSum = 0;

        for (int i = 0; i < nums.length; i++) {
            int rightSum = totalSum - leftSum - nums[i];

            if (leftSum == rightSum) {
                return i;
            }

            leftSum += nums[i];
        }

        return -1;
    }
}
```

核心公式：

```text
总和 = 左边 + 当前元素 + 右边
右边 = 总和 - 左边 - 当前元素
```

最重要的顺序：

```text
先判断当前 i
再执行 leftSum += nums[i]
```

因为判断当前中心下标时，`leftSum` 不能包含当前元素。

## 两种写法复杂度对比

| 写法 | 时间复杂度 | 额外空间 |
|---|---:|---:|
| 当前暴力版 | `O(n²)` | `O(1)` |
| `totalSum + leftSum` | `O(n)` | `O(1)` |
