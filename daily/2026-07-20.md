## 2. 自己最终 Accepted 的代码

```java
class Solution {
    public int largestAltitude(int[] gain) {
        int maxgain = 0;
        int n = gain.length;
        int current = 0;

        for (int i = 0; i < n; i++) {
            current = current + gain[i];

            if (current > maxgain) {
                maxgain = current;
            }
        }

        return maxgain;
    }
}
```

> 上面只统一了缩进和空格，保留实际提交通过的逻辑。

## 3. 算法过程

输入：

```text
gain = [-5, 1, 5, 0, -7]
```

从起点海拔 `0` 开始：

| 路段变化 | 当前海拔 `current` | 历史最高 `maxgain` |
|---:|---:|---:|
| 起点 | 0 | 0 |
| -5 | -5 | 0 |
| +1 | -4 | 0 |
| +5 | 1 | 1 |
| 0 | 1 | 1 |
| -7 | -6 | 1 |

最终最高海拔是：

```text
1
```

这就是累计和：

```java
current = current + gain[i];
```

当前状态由“上一轮状态 + 本轮变化”得到。

## 4. 为什么 `maxgain` 必须从 0 开始

旅行开始时已经位于海拔：

```text
0
```

起点也属于整段路线的一部分。

例如：

```text
gain = [-4, -2, -3]
```

后续海拔全部低于零：

```text
0 → -4 → -6 → -9
```

最高海拔仍然是起点 `0`。

所以：

```java
int maxgain = 0;
```

不仅是默认值，也是题目逻辑的一部分。

### 可以改进

变量名可以更清楚：

```java
int maxAltitude = 0;
int currentAltitude = 0;
```

这一段：

```java
current = current + gain[i];
```

可以简写成：

```java
current += gain[i];
```

判断最大值也可以使用今天允许查询的方法：

```java
maxAltitude = Math.max(maxAltitude, currentAltitude);
```

推荐简化版：

```java
class Solution {
    public int largestAltitude(int[] gain) {
        int currentAltitude = 0;
        int highestAltitude = 0;

        for (int change : gain) {
            currentAltitude += change;
            highestAltitude = Math.max(highestAltitude, currentAltitude);
        }

        return highestAltitude;
    }
}
```

当前自己的版本已经正确；上面只是可读性优化，不是另一种算法。

# 任务 2｜Find Pivot Index

## 1. 题目

[724. Find Pivot Index](https://leetcode.com/problems/find-pivot-index/)

- **中文：** 寻找数组的中心下标
- **难度：** Easy
- **当前状态：** 等待开始
- **预计时间：** 45～60 分钟

## 2. 题目目标

寻找下标 `i`，使它左边数字之和等于右边数字之和。

例如：

```text
nums = [1, 7, 3, 6, 5, 6]
```

下标 `3`：

```text
左边：1 + 7 + 3 = 11
右边：5 + 6     = 11
```

因此返回：

```text
3
```

## 3. 今天使用的累计和思路

不要对每个下标重新计算两边，避免 `O(n²)`。

先求总和：

```java
int totalSum = 0;
```

然后从左到右维护：

```java
int leftSum = 0;
```

检查下标 `i` 时：

```text
rightSum = totalSum - leftSum - nums[i]
```

因为总和由三部分组成：

```text
总和 = 左边 + 当前元素 + 右边
```

所以：

```text
右边 = 总和 - 左边 - 当前元素
```

## 4. 最容易写错的顺序

判断当前 `i` 时，`leftSum` 不能包含 `nums[i]`。

正确顺序：

```java
// 先检查当前 i 的左右和

// 检查结束后再更新
leftSum += nums[i];
```

如果先加进去，就会把当前元素错误算到左边。
