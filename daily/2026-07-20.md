## 任务 1｜热身必做

[1732. Find the Highest Altitude](https://leetcode.com/problems/find-the-highest-altitude/)

- **中文：** 找到最高海拔
- **难度：** Easy
- **预计时间：** 25～35 分钟

### 先理解

旅行从海拔 `0` 开始：

```text
gain = [-5, 1, 5, 0, -7]
```

每走一段，就把变化量加到当前海拔：

```text
开始：0
加 -5：-5
加  1：-4
加  5： 1
加  0： 1
加 -7：-6
```

过程中的最大值是 `1`。

### 需要的变量

可以考虑：

```java
int currentAltitude = 0;
int highestAltitude = 0;
```

每轮做两件事：

1. 更新当前海拔；
2. 更新历史最高海拔。

允许使用：

```java
Math.max(a, b)
```

## 任务 2｜补进度主任务

[724. Find Pivot Index](https://leetcode.com/problems/find-pivot-index/)

- **中文：** 寻找数组的中心下标
- **难度：** Easy
- **预计时间：** 45～60 分钟

### 题目目标

寻找一个下标 `i`，使它左边所有数字之和等于右边所有数字之和。

例如：

```text
nums = [1, 7, 3, 6, 5, 6]
```

下标 `3` 的值是 `6`：

```text
左边：1 + 7 + 3 = 11
右边：5 + 6     = 11
```

所以答案是 `3`。

### 不要为每个位置重新计算左右两边

暴力做法会对每个下标重复求和，可能是 `O(n²)`。

更好的思考方式：

1. 先求整个数组总和 `totalSum`；
2. 扫描时维护左边之和 `leftSum`；
3. 当前下标右边的和可以算出来：

```text
rightSum = totalSum - leftSum - nums[i]
```

4. 如果：

```text
leftSum == rightSum
```

就找到中心下标；
5. 检查完当前下标后，再把 `nums[i]` 加到 `leftSum`。

### 特别注意顺序

在判断当前下标时，`leftSum` **不能包含 `nums[i]`**。

正确顺序是：

```text
先判断当前 i
再执行 leftSum += nums[i]
```
